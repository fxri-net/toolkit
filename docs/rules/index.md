# 全局规则

> 三份可复制的全局规则模板，按需取用；彼此独立，可只复制其中一份或任意组合。

## 规则清单

| 规则 | 适用对象 | 复制方式 |
| --- | --- | --- |
| [AI 全局规则](./ai) | 通用 AI 协作纪律：代码规范、输出要求、方案落盘与验证 | 复制「规则全文」代码块 |
| [提交信息规则](./commit) | 统一 git 提交信息格式与语义 | 复制「规则全文」代码块；与 Conventional Commits / commitlint 互斥 |
| [技能使用情况规则](./usage) | 启用 toolkit 技能使用统计后，约束 AI 不重复补记、不外传数据 | 可选；复制「规则全文」代码块，或执行 `toolkit usage rule` |

## 如何组合

- 三份规则彼此独立，可只取其一，也可任意组合；同时使用时分别复制到 Agent 的全局规则文件。
- 技能使用情况规则默认不启用采集；只有开启 `toolkit usage` 后才需要复制。

## 同步与自查

- 每篇规则全文的**首行**都是 `> 规则更新时间 YYYY-MM-DD HH:mm`；快照首行与本页当前值不一致，即说明已失同步，重新复制对应页即可。
- 规则是薄壳：可变流程细节在 fxri-* skills 中随包分发，升级 skills 后无需再手动同步规则全文。
