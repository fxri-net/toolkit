# 推荐个人偏好规则

> 可选规则：本页是作者自用的个性化偏好，按你的习惯增删后复制到 Agent 全局规则。
> 与 [AI 全局规则](./ai)、[提交信息规则](./commit)、[技能使用情况规则](./usage) 相互独立，可只取其一，总览见[全局规则索引](./)。

## 解决什么问题

纪律类规则对所有用户相同，偏好却因人而异：收尾时是否自动提交、看到版本提示是否提醒升级，都取决于各人的工作方式。
把偏好单独成页，纪律模块保持统一，偏好改动只影响这一页，升级时也不会因个人差异反复覆盖。

## 规则全文（可直接复制）

````markdown
> 规则更新时间 2026-11-20 11:52

## 个人偏好

- 以下条目覆写《工作流》的默认行为，两者冲突时以本章为准。
- 任务收尾的 git 提交自动执行：归档与规范沉淀完成后直接提交，任务记录与代码变更落在同一提交；推送与发版仍须明确授权。
- 看到 CLI 的版本提示时提醒用户升级，不代跑安装命令。
- skill 指引、help 输出与 check 反馈不一致时，以 check 的实际反馈为准。
- 计划表列出过、或上一任务执行过的同类动作，不构成本次授权。
````

## 可裁剪说明

- 每条都可以删：删掉「收尾提交自动执行」即回到默认的「提交需确认」，删掉「提醒升级」即不再主动提示版本。
- 建议只保留与你工作方式一致的条目，不必整篇复制。
- 与《工作流》冲突时本章优先；不想要的偏好直接删除，不要改成相反表述后与纪律并存。

## 快照自查

首行「规则更新时间」与本页当前值不一致，即说明你的规则快照落后，重新复制本页即可。
