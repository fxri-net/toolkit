# 推荐个人偏好规则

> 可选规则：本页是作者自用的规则层偏好，按你的习惯增删后复制到 Agent 全局规则。
> 这里的「个人偏好」指规则条目，与 `.toolkitrc.json` 的配置项不是一回事。
> 与 [AI 全局规则](./ai)、[提交信息规则](./commit)、[技能使用情况规则](./usage) 相互独立，可只取其一，总览见[全局规则索引](./)。

## 解决什么问题

纪律对所有使用者相同，取舍却因人而异：任务收尾是等你点头再提交，还是归档完直接提交，取决于你的习惯。
把它单独成页，纪律模块保持统一，你改偏好也只影响这一页。

## 规则全文（可直接复制）

````markdown
> 规则更新时间 2026-11-24 09:57

## 个人偏好

- 以下条目优先于同类默认约定。
- 任务收尾的 git 提交自动执行。
````

## 可裁剪说明

- 每条都可以删：删掉「收尾提交自动执行」，即回到 [AI 全局规则](./ai) 的默认「提交需你确认」。
- 只写与你想要的默认相反的条目，不必整篇复制；改回默认就删掉该条，不要改成相反表述后与纪律并存。
- 可删的是默认行为的选择，不是真源指向与红线——那些在纪律模块里，不受本页影响。

## 快照自查

首行「规则更新时间」与本页当前值不一致，即说明你的规则快照落后，重新复制本页即可。

## 模块来源

本文对应 `personal` 模块，`complete` 与 `full` 预设均含该模块，也可在[规则组合器](./)中单独勾选或与其他模块组合。
