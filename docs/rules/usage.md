# 推荐技能使用情况规则

> 可选规则：默认不启用采集，需要时复制下方全文到 Agent 全局规则。与 [AI 全局规则](./ai)、[提交信息规则](./commit) 相互独立，可只取其一，总览见[全局规则索引](./)。

## 解决什么问题

技能使用统计由本地 Hook 自动采集。没有规则时，AI 容易在任务收尾时手工补记造成重复计数，或把数据文件当普通文件改写、把导出内容发到未授权地址。本规则用四句话把边界定住。

## 规则全文（可直接复制）

````markdown
> 规则更新时间 2026-11-06 16:06。本规则内容变更时以变更时刻更新此值；快照与本页当前值不一致即说明已失同步，重新复制本页即可。

## Skill usage（技能使用情况）
- 技能使用统计由 toolkit 的本地 Hook 自动记录；开启后无需手工补记，避免重复计数。
- 记录默认只保存在本机，不会上传网络；上传需用户显式开启并配置端点。
- 查看统计使用 `toolkit usage stats`；状态异常先运行 `toolkit usage doctor`。
- 不要自行修改使用情况数据文件或把导出内容上传到未授权地址。
````

同一份文本可由 `toolkit usage rule` 输出，文档与命令同源，避免两处漂移。

## 注意

- 规则是薄壳，不包含具体 Agent 路径、事件字段或配置细节；这些随技能与 CLI 版本演进。
- 是否启用仍由用户决定；不要因为规则存在就默认开启采集。
- 已复制过旧版规则（含 `telemetry` 命令）的，请重新执行 `toolkit usage rule` 覆盖。
