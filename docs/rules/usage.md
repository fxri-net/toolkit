# 推荐技能使用情况规则

> 可选规则：默认不启用采集，需要时复制下方全文到 Agent 全局规则。与 [AI 全局规则](./ai)、[提交信息规则](./commit) 相互独立，可只取其一，总览见[全局规则索引](./)。

## 解决什么问题

技能使用统计有两条通道，二选一：默认的**规则上报**由 AI 在每批工具调用后按本规则显式上报，不依赖任何 Agent 配置；需要自动触发时可改用 **Agent Hook**（见 [Agent 接入](../usage/agents)）。没有规则时，AI 容易在任务收尾时手工补记造成重复计数，或把数据文件当普通文件改写、把导出内容发到未授权地址。本规则用五句话把边界定住。

## 规则全文（可直接复制）

````markdown
> 规则更新时间 2026-11-07 12:26。本规则内容变更时以变更时刻更新此值；快照与本页当前值不一致即说明已失同步，重新复制本页即可。

## Skill usage（技能使用情况）
- 每批工具调用全部返回后，若本批用到了技能，就合并执行一次 `toolkit usage record --skill <名称> [--skill <名称> ...]` 上报；一批 = 同一批工具调用全部结束，本批未用技能则不调用。
- 规则只传技能名，触发词与参数不由规则转述；是否统计、统计哪些技能由本机 usage 配置决定（`toolkit usage info` 查看）。
- 上报静默执行，失败不阻断当前任务；记录只保存在本机，上传需用户显式开启并配置端点。
- 查看统计使用 `toolkit usage stats`；状态异常先运行 `toolkit usage doctor`。
- 不要自行修改使用情况数据文件或把导出内容上传到未授权地址。
````

同一份文本可由 `toolkit usage rule` 输出，文档与命令同源，避免两处漂移。

## 注意

- 规则是薄壳，不包含具体 Agent 路径、事件字段或配置细节；这些随技能与 CLI 版本演进。
- 只统计规则中上报的技能，且必须命中本机 `usage` 配置（总开关、来源、技能范围）；未命中的技能静默忽略，不产生记录。
- 规则通道与 Hook 通道由 `usage.channel` 二选一：选 `rule` 时 Hook 不写入，选 `hook` 时规则上报不写入，避免同一调用被记两次。
- 是否启用仍由用户决定；不要因为规则存在就默认开启采集。
- 已复制过旧版规则（含 `telemetry` 命令或「Hook 自动记录」表述）的，请重新执行 `toolkit usage rule` 覆盖。
