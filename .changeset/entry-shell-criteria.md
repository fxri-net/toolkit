- 修改：`toolkit task init` 的技能入口壳改为「标记版本 + 正文比对」双判据，标记一致但正文与模板不同同样就地重写，修复壳文案已漂移却因版本未变而静默跳过的问题
- 修改：入口壳标记改为两段式 `v2.1`（正文变更抬次版本、结构或协议变更抬主版本），旧 `v2` 标记按 `v2.0` 解析
- 新增：`toolkit convention status` 与 `toolkit task check` 增加「标记一致但正文与模板不一致」软告警，与版本不一致告警分开报告
- 新增：`pnpm bump:entry-version` 脚本——壳模板变更时自动抬次版本并刷新模板快照，避免版本与正文脱节
