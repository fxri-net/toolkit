# 触发样例

> 供人工回归：被动语义触发为主，显式话术为辅。样例非穷举。

## 该触发

- 「落档了，继续评估」
- 「这些任务拆分合理吗？」
- 「是不是拆得太细 / 太粗？」
- 「有没有漏掉的地方？」
- 「复核一下任务」
- 「重新评估开发计划」
- 用户先明确「全部接受」，随后说「开始」——应用 `直接落档` 项，`需要确认` 仍逐条问

## 不该触发

- 初次方案讨论、还没有任务清单
- 单纯说「落档」「归档任务」「开始发版」
- 「评估技术方案性能」「评估依赖版本」
- 「帮我写个 README」等与任务集无关的请求
- 含糊回应「嗯」「再说」「再看看」——不自动落档
- 只说「继续评估」「可以吧」「开始」但未表明接受评估结论——只继续讨论，不写盘
