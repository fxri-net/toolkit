# 交互路径真终端测试

> 本技能版本 0.1.2（随 @fxri/toolkit 同批分发）。被问版本时即报此值（不读磁盘、不跑 CLI）；与 `toolkit skill status` 的磁盘值不一致即说明会话上下文已过期，开新会话即可。

本技能沉淀自一轮 `node-pty` + Windows ConPTY 真机实测：5 条交互路径、13 项断言全部通过，覆盖选择与取消、两级向导、多选与确认；
抽象为「CLI 入口 + 交互用例表」，不绑定具体命令。

## 何时使用

- 需要验证 CLI 的交互路径：选择列表（单选 / 多选）、确认框、向导流程、取消与中断。
- 交互行为无法用 `--yes` 或参数化路径覆盖，必须验证真实按键流转。
- 交互测试「手工能过、脚本断言失败」：输出噪声、确认框默认值、配置查找穿透等。

不适用：单元测试、快照测试、非 TTY 的 stdout 断言、浏览器 UI 自动化。

## 四步流程

### 1. 沙箱

- 每条用例一个临时目录，结构固定：`<sandbox>/<home>` 作 HOME / USERPROFILE，`<sandbox>/<home>/work/<case>` 作 cwd。
- ⚠️ home 必须是 work 的**祖先**：CLI 从 cwd 向上查找配置，home 若为兄弟目录，查找会越过沙箱落到真实用户目录，用例互相污染且会改到本机配置。
- 一并覆写平台配置目录（`XDG_CONFIG_HOME`、`APPDATA`、`LOCALAPPDATA`），路径全部 `realpath` 归一（macOS 的 `/var` 是软链）。
- 用例结束整目录删除，不给真实用户目录留任何写入口。

### 2. 驱动

- 用 `node-pty` 起真 TTY：直接 spawn 运行时（如 `process.execPath` 加 CLI 入口），不套 shell，免去引号与转义差异。
- 固定 `cols` / `rows`，避免换行位置随终端尺寸漂移。
- 等待策略按**提示文案**，不按固定 sleep：短轮询新增输出，命中预期片段再发下一键。
- 按键：方向键 `\x1b[A` / `\x1b[B`，空格切换多选，`\r` 提交，`\x1b` 取消，`y\r` / `n\r` 显式回答，`\x03` 中断。
- 每次收尾都 kill 并等待退出；超时即判失败，不留孤儿进程。模板见 `references/pty-driver.md`。

### 3. 用例

- 用例表每行固定五列：`<CASE>`、`<CLI>` 调用参数、按键序列、期望退出码、期望落盘 / 不应出现。
- 覆盖三类路径：正选（含多选）、取消与中断、默认值（只回车走默认分支）。
- 断言口径写进用例表，不在驱动代码里散落字符串匹配。

### 4. 断言与清理

- 先清洗 ANSI 与平台噪声再断言；原始日志单独保留，失败时优先看原始日志。
- 必查：退出码、落盘产物（存在 / 内容 / 数量）、取消路径不写、确认框默认值、home 隔离（真实用户目录无新增）。
- 同一条用例的断言全部通过才算过，部分通过按失败处理；清单见 `references/assertions.md`。
- 清理进程与临时目录后再跑下一条，避免残留状态影响后续用例。

## 三个必踩坑

1. **home 沙箱层级**：home 必须包住 work。两者平级时，配置向上查找会穿透沙箱进入真实用户目录。
2. **确认框默认值**：`(y/N)` 默认拒绝，盲发 `\r` 等于取消。要接受就显式发 `y\r`；要验证默认分支，则专门断言「只发 `\r` 后不发生写入」。
3. **ConPTY 噪声**：Windows 驱动会输出 `AttachConsole failed` 一类与业务无关的行，断言前剔除，否则关键字匹配被污染。

## 失败回退

- 原生模块装不上（无预编译二进制、离线）：本技能按需执行，不挂默认门禁；改用非交互路径验证，并**明确标注交互路径未验证**，不静默降级。
- 无输出或超时：先看原始日志与终端尺寸，把固定等待改成「等提示文案」，再判产品缺陷。
- 断言失败先分流：home 穿透、默认值理解错、噪声未清洗属测试自身问题；清洗后仍失败才按产品缺陷上报。

## 边界与注意

- `node-pty` 为原生模块、需联网安装，定位按需 E2E，不加入 `pnpm verify` 等默认门禁。
- Windows 走 ConPTY（较新系统），旧环境回退 winpty 行为不同，断言不要依赖具体转义序列。
- 只断言关键提示与结果，不复刻整屏渲染；光标移动、清屏、重绘一律按噪声处理。
- 命令与路径一律用 `<CLI>` / `<CASE>` 占位，套用时不把具体仓库路径写进模板。
