# 断言清单

> 本文件是 `fxri-test-tty` 的明细附表；流程与坑位以 `SKILL.md` 为准。

一条交互用例至少覆盖五类断言：退出码、落盘产物、取消不写、确认默认值、home 隔离。
全部通过才算过，部分通过按失败处理。

## 1. 退出码

| 退出码 | 常见语义 | 断言要点 |
| --- | --- | --- |
| `0` | 成功 | 与落盘产物同时断言：成功路径必须真的产生了预期写入 |
| `1` | 操作失败或校验存在 error | 失败路径断言 stderr 有原因，且未产生半成品 |
| `2` | 需要交互但当前环境不支持 | 非 TTY / CI 场景专用；断言 stderr 给出非交互替代 |
| `3` | 守卫判定未激活等业务拒绝 | 只出现在特定命令；按被测 CLI 文档确认，不套用到其他命令 |
| `130` | 用户在交互提示中中断 | 必须叠加「不写任何文件」，见第 3 节 |

- 退出码口径以被测 CLI 的文档为准；本表只记常见含义，不替代其真源。
- 非预期退出码的失败信息里带上最近 400 字符输出与 stderr，避免只报一个数字。

## 2. 落盘产物

- **先拍基线**：启动前记录沙箱内的文件清单（路径、大小、内容哈希），运行后对比新增与修改。
- **逐项断言**：产物存在、内容关键片段、数量（多选用例断言选中项个数与命名一一对应）。
- **只断言契约**：不断言整文件逐字节相等，除非产物本身是稳定格式；易变字段（时间戳、随机 ID）按结构断言。
- **不复刻实现**：派生 / 镜像类结果直接调用真实实现或读取真实产物，不在测试里重写同一份转换逻辑，否则实现错了测试也跟着错。

## 3. 取消不写

- 取消路径有两种触发：向导内按 `\x1b`（逐级返回）、按 `\x03`（整体中断，退出码 `130`）。
- 两种都要断言：**目标文件与状态文件在运行前后完全一致**（路径集合与内容哈希都不变）。
- 若取消前已完成部分步骤，还要断言没有留下临时文件、锁文件、半写入的目标文件。
- 只断言退出码为 `130` 不够：中断退出但已写入同样算失败。

## 4. 确认框默认值

- 先断言提示文案里的默认值，如 `(y/N)` 默认拒绝、`(Y/n)` 默认接受。
- `(y/N)` 场景至少两条用例：
  - 只发 `\r`：按默认拒绝处理，断言**没有**发生写入；
  - 发 `y\r`：断言写入发生。
- ⚠️ 盲发 `\r` 等于选择默认值，不是「确认」；把「回车即通过」写成断言会掩盖真实缺陷。
- 提示文案随语言或措辞变化时，用正则匹配括号内的默认值形态，不绑定整句。

## 5. home 隔离

- 断言真实用户目录在运行前后无新增文件（这是沙箱层级是否正确的最直接证据）。
- 断言沙箱内出现预期的配置 / 状态文件，说明被测进程确实读写的是沙箱。
- 断言输出里不出现真实用户目录路径（如残留的绝对路径提示）。
- 沙箱结构为 home 包住 work（见 `pty-driver.md`）；发现穿透先修沙箱，不改产品断言。

## 6. 按键序列与噪声处理

- **按键只发一次**：等提示命中再发；重复发送会在慢机器上产生双输入（如方向键连跳两项）。
- **方向键**每按一次移动一项；多选用空格切换当前项，不要用方向键模拟点选。
- **中断与返回要分开**：向导内 `\x1b` 通常只返回上一级，`\x03` 才整体中断；断言前确认被测 CLI 的实际语义。
- **清洗规则**（断言前统一执行）：
  - 去掉 CSI 序列（颜色、光标移动、清屏）与 OSC 序列（窗口标题）；
  - 去掉 Windows ConPTY 的 `AttachConsole failed` 行；
  - 把 `\r` 覆盖与连续空行归一，便于按行匹配；
  - 保留原始日志，失败时输出原始片段而不是只输出清洗结果。
- **断言对象是语义文本**：匹配提示关键字、选项名、结果行；不匹配颜色码、光标位置、整屏快照。
- **多选 / 长列表会重绘**：同一提示可能出现多次，等待逻辑只消费新增输出，避免把历史渲染当成下一次。

## 7. 清理

- `finally` 里 kill 进程、等待退出、删除沙箱；Windows 下等待 conhost 释放句柄后再删目录。
- 清理失败只告警，不掩盖断言失败；但孤儿进程会让后续用例互相干扰，需在报告里点名。
