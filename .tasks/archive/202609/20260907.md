# scope 多值加号口径与三道防线

> 延续 20260903-唐启云-toolkit-fg批次（见 archive/202609/20260903.md）——该任务实现 F12 查询侧 `--owner/--scope` 逗号多值过滤；本任务落地存储侧 scope 多值口径与污染防线，属同域增量。

## 背景

任务文件 frontmatter 的 scope 字段（`影响范围`）为自由文本，规格对多值写法零规定，导致实际数据出现中文顿号列表（`service-job、admin-facade、pub-facade(注释)`）与加号复合（`toolkit+lxgl-web`）等漂移形态，而 stats 按整串聚合、过滤按整串精确匹配，工具行为与「一任务多归属」的期望语义背离。归档真实数据中唯一复合值即加号写法，多值归属是真实需求。

## 实施方案

**口径**：scope 多值以半角加号 `+` 分隔（如 `scope: toolkit+lxgl-web`）；过滤按「任一命中」、统计按段拆桶；三道防线拦截顿号/括号/逗号污染。存量唯一复合值 `toolkit+lxgl-web` 天然合规，零数据迁移。

1. **query.ts**：新增导出 `splitScope`（按 `+` 拆、逐段 trim、忽略空段）；新增 `scopeHit`（过滤值数组任一段命中存储任一段）；`matchRow` 的 scope 过滤改用 `scopeHit`（owner/status 保持整串精确）。
2. **stats.ts**：`byScope` 对 scope 拆段后逐段 bump（`core+docs` 双桶各 +1）。
3. **validate.ts**：`validateTaskFile` 增 scope 软告警（warn）——含顿号 `、` 或全/半角逗号 →「疑似顿号/逗号分隔多值，多值请改用半角加号连接」；含全/半角括号 →「疑似注释性文字，说明请移入正文」。软告警检测集收敛为高置信项，斜杠/空格不纳入（噪音）。
4. **import.ts**：`normalizeRecord` 检测 scope 含顿号/逗号/括号 → push warnings「范围将按单值写入；多值请用半角加号，注释放正文」（只提示不自动转换，转换语义二义）。
5. **normalize.ts**：`checkArchive` 对归档 meta 行「范围：」值含顿号/逗号报 issue（fixable:true），含括号报 issue（fixable:false 人工）；`fixArchive` 把顿号/逗号段归一为 `+` 并重写 meta 行（计 fixed），括号污染 push 入 issues 随 `--fix` 输出（不自动删，删除是语义决定）。
6. **types.ts**：`TaskFilter.scope` 注释更新为「命中任务范围任一段（存储以半角加号分隔多值）」。
7. **测试**：query/stats 多值命中与拆桶、validate 三类污染 warn 与合法值静默、normalize check/fix 可修/不可修两分支、import 入口提示各补用例。
8. **文档与 skills**：SPEC.md、task-spec.md、docs/cli.md、docs/api.md 同步口径；fxri-plan-to-task SKILL.md version +patch。
