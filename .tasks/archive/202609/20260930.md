# 项目侧技能分发与真源薄壳

> 来源链：延续 `20260912-唐启云-skills包内分发与全局安装`（见 `.tasks/archive/202609/20260912.md`）、`20260926-唐启云-规范载体v2与入口壳`、`20260926-唐启云-入口壳多落点与触发面补强`（见 `.tasks/archive/202609/20260926.md`）。

## 背景

### 现状（改造前）

- `toolkit skills install` 的目标解析恒为**全局**：`src/skills.ts` 的 `resolveSkillTargets()`（L520-541）只用 `getHomeDir()` 展开 `CANONICAL_DIR` 与 `AGENT_SKILL_DIRS`，与 CLI 装在哪无关。
- 包无 `postinstall` / `prepare` 钩子，故项目内装完 CLI 后仍须手动跑一次 `toolkit skills install`，且落点仍在全局。
- 结果：项目里装了 toolkit，技能却散落在用户机器的全局目录——不随 git 分发，队友 clone 后拿不到，每台电脑都要重来一遍。

### 诉求

1. 项目内安装的 toolkit 把技能分发到**项目内**（随 git 分发，clone 即用）；全局安装的分发到全局；作用域**自动判定**，不靠用户记参数。
2. 项目侧技能采用**唯一真源 + 多份薄壳**形态：完整副本只留一份（`.agents/skills/`，入库、恒定存在），其余已存在的 agent 技能目录各放一个薄壳 `SKILL.md`，指向真源。
3. 升级后项目侧自动刷新（`prepare` 钩子，由 `toolkit init` 幂等写入），消除重复手动步骤。

## 实施方案

### 设计定稿

```
<用户项目>/
├── .agents/skills/                    # 唯一真源：完整副本（入库）——恒定存在
│   ├── fxri-plan-to-task/{SKILL.md, references/, assets/}
│   ├── fxri-session-recap/SKILL.md
│   ├── fxri-release-changelog/{SKILL.md, references/}
│   └── toolkit-conventions/SKILL.md   # 既有壳（指向 .tasks/conventions，由 init 维护）
├── .trae-cn/skills/                   # 薄壳（该目录已存在时；其余候选目录同构）
│   ├── fxri-plan-to-task/SKILL.md     #   description 派生自真源 + 指向真源路径 + 版本标记
│   ├── fxri-session-recap/SKILL.md
│   └── fxri-release-changelog/SKILL.md
├── .toolkit/state.json                # 项目态归属账（入库、记仓库相对路径）
├── .tasks/                            # 契约不变（入库）
└── package.json                       # prepare：刷新真源一份 + 按需重写薄壳
```

全局侧形态不变：`~/.agents/skills/fxri-*`（软链）+ `~/.agents/.toolkit-skills.json`。

### 批次 1：作用域判定与项目侧目标解析

- `src/skills.ts` 新增 `SkillScope = "project" | "global"` 与 `detectSkillScope(cwd)`：判据取 **CLI 包根真实形态是否为 cwd 真实形态的祖先**（`resolvePackageRoot()` + `fs.realpathSync.native` 归一，遵 C-32），不用 cwd 单独判定，避免「全局 CLI 在项目目录内执行」误判。
- 项目侧目标解析：真源固定 `<repo>/.agents/skills`（恒定，不存在则创建）；薄壳目标复用 `src/conventions/entry.ts` 的 `PROJECT_SKILL_DIRS` / `resolveProjectSkillDirs`（其余已存在的候选目录，只写已存在目录，不凭空造）。

### 批次 2：项目侧写入（真源副本 + 薄壳）

- 真源：逐技能 `cpSync` 完整目录（幂等：内容一致跳过）。
- 薄壳：每个技能一个 `<候选目录>/<技能名>/SKILL.md`，内容 = frontmatter（`name` 与目录同名、`description` 从真源 frontmatter 抽取）+ 版本标记 + 正文指向真源路径；版本分流沿用 `toolkit-conventions` 壳四手法（落后重写 / 同版跳过 / 超前不降级 / 只写已存在目录）。
- 薄壳正文明确指示 agent 读取真源目录下的完整 `SKILL.md`、`references/`、`assets/`。

### 批次 3：项目态归属账与 CLI 作用域开关

- 新增 `<repo>/.toolkit/state.json`：记真源路径与各薄壳落点（仓库相对路径），仅内容变化时写，消 diff 噪声；与全局 `~/.agents/.toolkit-skills.json` 分账。
- `skills install` / `status` / `remove` 增 `--scope <project|global|all>`，默认由 `detectSkillScope()` 决定；报告回显作用域与判定依据，并列出未命中的候选目录 + 可直接复制的 `--dir` 命令（遵 C-26 降级不静默）。
- `autoLinkSkills()` 保持全局语义，项目侧不参与软链自愈（项目侧是副本 + 壳，无软链）。

### 批次 4：`toolkit init` 写入 prepare
