# 技能分发支持 home 环境变量覆盖

来源链：延续「补齐 DeepSeek Harness 与 eve 的技能分发覆盖」（见 `archive/202610/20261019.md`），补齐上游 agent 全局目录对 home 类环境变量的跟随。

## 背景

`src/skills.ts` 的 `AGENT_SKILL_DIRS` 把各 agent 全局技能目录写死为相对 `os.homedir()` 的固定路径。上游 `vercel-labs/skills` 的 `agents.ts` 中，11 条目录的基准目录会被环境变量改写（6 条跟随 `XDG_CONFIG_HOME`，5 条跟随各自 `*_HOME`），另有 3 条仅用于探测的环境变量（`CODEX_HOME`、`SARVAM_HOME`、`APPDATA` / `FLATPAK_XDG_CONFIG_HOME`）。当前实现在用户设置这些变量时分发到错误目录，`detect` 可用性判定也随之失真。

## 实施方案
