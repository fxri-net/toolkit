# 方案规范对照前置到规划技能

> 计划位置：第 8 个（共 8 个）；前置：`20261127-唐启云-收敛技能族为-base-并迁移-code-族`；后继：无

## 背景

用户要求「确保方案里的所有东西都符合项目的相关规范」，但当前只能靠用户每次口头提醒：
- `fxri-plan-task` 只要求读 conventions 索引，没有要求把命中项与结论落到任务档；
- `fxri-plan-review` 的复核清单没有「规范对照」项；
- 如果只写进本仓库的 AGENTS / conventions，对外分发时其他项目拿不到这条能力。

因此本任务把这套能力写进**随包分发的规划技能**，且必须通用：不依赖某个项目的固定规范清单，
也要能处理用户提出的新东西。

## 实施方案

1. `skills/fxri-plan-task/SKILL.md` 建档前置步骤增加一条「规范对照」：
   按规范来源判断命中，命中项与结论写入任务档；无命中写理由；新事物先登记或确认，不硬套旧条目；
   并在参考 / 读取地图节指向 `references/norm-check.md`，保证新增 reference 可解析。
2. 新增 `skills/fxri-plan-task/references/norm-check.md`，写通用口径（不出现本仓库专属 C-xx / 文件路径）：

     → 配置、schema 与契约 → 既有代码与测试约定 → 用户明确约束。
   - 逐项判断：命中哪个来源 / 规则、要求是什么、方案怎么满足；写入任务档的影响范围或验证方式。
   - 无命中：写「规范对照：无命中」并给一句理由，不空泛带过。
   - 新事物：项目有登记机制时先登记；没有登记机制时写明新增假设或规则，并询问用户是否沉淀；不得硬套旧条目。
   - 输出可简写为 `- 规范对照：<来源> <ID/条款> → <结论>`。
3. `skills/fxri-plan-task/references/task-spec.md` 的自查清单增加「规范对照已完成并留痕」一项。
4. `skills/fxri-plan-review/references/review-checklist.md` 增加「规范对照」检查行：
   规范来源是否识别、命中项与结论是否留痕、新事物是否登记或确认、是否硬套旧条目。
5. 版本递增：以任务 6 后的真源版本为起点，`fxri-plan-task` 1.13.20 → 1.13.21、`fxri-plan-review` 1.1.6 → 1.1.7；

6. 变更集：patch，条目 `- 文档：规划与复核技能补充规范对照前置与留痕要求`。

# 修正变更集版本口径

> 计划位置：第 6 个（共 8 个）；前置：`20261127-唐启云-修复技能改名后重装残留旧名产物`；后继：`20261127-唐启云-收敛技能族为-base-并迁移-code-族`

## 背景

用户指出 patch 变更集可以挂 `重大：` 分组，且已有先例：
`.changeset/scope-command-reorg.md` 的 frontmatter 为 `"@fxri/toolkit": patch`，条目为 `- 重大：移除 ...`，
对应 `CHANGELOG.md` 的 `2.0.5` 重大变更块。

当前 `skills/fxri-release-changelog/references/changelog-format.md` 却写死了相反口径：
- L61「bump ... 至少 minor，不可降至 patch」
- L113「`重大：`（破坏性）不可降至 patch」

这与同文件 L42/L86「类型前缀与 bump 正交」以及 `SKILL.md L62-64` 的表述自相矛盾，导致按规则执行会误判。

## 实施方案

1. 统一修订 `references/changelog-format.md` 的「版本口径」全节，不只改三处：
   - L61：`重大：` 只标注破坏性，不决定 bump；可与 patch 共存，但条目须写清旧 → 新迁移或重装路径。
   - L93 / L97 / L99 / L111 / L112 / L115：minor 判据统一为「破坏既有用法且无自动迁移 / 重装路径」；
     有迁移路径的破坏性变更可按 patch，用户仍需手动改现有用法才按 minor。
   - L113 / L123 / L124 / L127：删除「`重大：` 不可降至 patch」「patch 只允许只增不改」的绝对表述；
     改为 patch 可挂 `重大：`，但破坏性条目必须附旧 → 新迁移映射与不兼容说明。
   - 保留 L42 / L86「类型前缀与 bump 正交」的表述，避免再次出现自相矛盾。
2. `skills/fxri-release-changelog/SKILL.md L62-64`：把「破坏既有用法需改 → minor」补成
   「破坏既有用法且无自动迁移 / 重装路径 → minor」；补一句「前缀与 bump 正交，patch 也可挂 `重大：` / `新增：`」。
3. 技能版本 `1.4.8` → `1.4.9`：frontmatter `metadata.version` 与正文首部版本行同步；
   `skills/README.md` 与 `docs/guide.md` 的版本列同步。

## 影响范围

- 技能表：`skills/README.md`、`docs/guide.md`（只改版本列）
- 变更集：`.changeset/changelog-bump-policy.md`
- 文档触达：skills/README.md、docs/guide.md
