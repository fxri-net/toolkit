# 变更集净变更规则

- 计划位置：toolkit 1 / 5；前置：无

## 背景

CHANGELOG 面向从上一已发布版本升级的用户。同一发布内的来回改动（新增某能力后又在同版本内修改、修复或回退）对读者不可见，逐条保留会让更新日志混入过程记录。当前 `fxri-release-changelog` 只做语义归类，并明确「归类只搬移、不删内容」，没有「同版本内后改动覆盖先改动」的编辑规则。

## 实施方案

1. `skills/fxri-release-changelog/SKILL.md`
   - 在「消费发版」之前插入「合并同版本变更集」步骤：按净用户可见结果收敛同一版本块的条目。
   - 判定标准：
     - 仅限同一包、同一版本块、本次发布内；不跨版本、不改历史块、不合并依赖变更。
     - 上一已发布版本中不存在的新能力，本次内的 `新增 → 修改 → 修复` 折叠为一条最终状态。
     - 上一已发布版本中已存在的行为，其 `修改` / `修复` 必须体现在最终条目中，不得整条丢弃。
     - 本版本内完全回退且从未发布的能力，整条删除。
     - 类型归并：`新增 + 修改/修复` 归新增，`修改 + 修复` 归修改，纯修复保留，重大变更不降级。
     - 无法确认同源时保留，不猜。
     - 输出折叠清单：保留哪条、哪条并入哪条、删除哪条及原因；过程记录留在变更集、提交与任务档。
   - 失败模式新增一行：同版本内过程性条目未收敛时，按净变更规则合并而不是继续堆叠。
   - 版本双写位同步升到 `1.3.0`。
2. `skills/fxri-release-changelog/references/changelog-format.md`
   - 新增「净变更合并」小节，给出判定表与正反例。
   - 把「归类只搬移、不删内容」限定为 CLI 格式化命令的行为，不约束人工净变更编辑。
3. `docs/guide.md`
   - 技能表版本更新为 `1.3.0`。
4. `.changeset/`
   - 新增 patch 变更集，描述净变更规则。
