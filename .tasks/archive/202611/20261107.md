# 去掉 git 调用的 shell 拼接

## 背景

`src/skills/source.ts` 的三处 git 调用带 `shell: process.platform === "win32"`。`shell: true` 时 Node 把参数数组拼成命令行交给 shell 重新解析，路径含空格（如 `C:\Users\John Doe\…` 的缓存目录）会被拆成多个参数而失败；同一份代码在 POSIX 上走另一条分支，属平台行为不一致。

## 实施方案

1. 三处 `spawnSync("git", args, { encoding: "utf8", shell: process.platform === "win32" })` 去掉 `shell` 选项，统一按参数数组直接执行（git 为 `.exe`，Node 可经 PATH 解析）。
2. 保留原有错误归因（`result.error` → 「git 不可用」）。
