# 项目协作规范（conventions）

> 本文件为「规范溯源簿」：记录本项目确立的每条规则、确立时的来源任务、演进历史，以及条文的单一事实源位置。条文内容一律以各单一事实源最新版为准（skills / task-spec / ai-rules / AGENTS），本文件不复制条文，避免版本漂移。
> 非任务文件，`toolkit tasks` 不读取、`check` 不告警。由任务归档（任务级）与会话收尾（会话级）维护，写入前经用户确认。

## 三、用法说明

- 本项目已具备完整规则层（AGENTS.md 治理 + ai-rules 全局规则 + skills 流程），故本文件采用**溯源索引式**：不复制条文，只记「确立了什么、谁确立的、条文去哪看」。
- 无其他规则文件的项目可选用**条文式**：本文件作为项目唯一规范载体存条文全文——两种形态 skill 的写入/读取机制均支持。
- 规则层源头变更时：修改 AGENTS.md / ai-rules.md / skills 条文的变更须同步检查本表对应行（当前语义是否需要更新），随该变更同批落盘；语义变更须先在「演进记录」留痕，再更新表内当前语义。
