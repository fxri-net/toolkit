# 项目协作规范（conventions）

> 本文件为项目协作规范的唯一沉淀地：由任务归档（任务级）与会话收尾（会话级）提炼，写入前经用户确认。非任务文件，`toolkit tasks` 不读取、`check` 不告警。每条带来源任务与日期，可审计。

## 时间与收尾

- **四级时间源**：任务时间字段取证优先级 = 当场打点（任务完成时取真实时间）> 聊天记录准确时间戳 > git 提交时间 > 系统当前时间兜底（须标注「收尾补记」）；禁止估算，禁止用收尾时刻冒充真实发生时刻
  - 来源：20260906-唐启云-会话收尾沉淀能力升级
- **能力终点 = 沉淀**：任务终结 → 归档 → 规范沉淀（硬终点）→ 提交/发版/推送（可选，需用户确认）；沉淀时机固定为归档后、任何 git 操作前，与归档文件同批落盘
  - 来源：20260906-唐启云-会话收尾沉淀能力升级

## 规范管理

- **唯一落点 conventions.md**：任务级（归档时）与会话级（收尾时）提炼写同一文件；写入前经用户确认；每条带来源任务标注；同义不重复记录，一次性决策留任务正文、不升格为规范
  - 来源：20260906-唐启云-会话收尾沉淀能力升级

## 会话恢复

- **近窗按时间连续性判定**：空洞隔断（≥1 年无归档）的旧归档仅入全量索引、不精读、不列为「最近完成」；active 任务 `updated` 距今 >1 年标注「疑似搁置」，建议确认收尾或放弃，不当进行中呈现
  - 来源：20260906-唐启云-会话收尾沉淀能力升级

## AI 协作

- **skill 触发靠语义不靠字面**：以行为意图画像 + 近义表达触发，带反例排除防误触发；作者个人口头禅不进通用触发词
  - 来源：20260906-唐启云-会话收尾沉淀能力升级
- **文档三层职责分离**：操作手册（docs/handbook.md）= 用户视图层（说「场景」→ 给「动作」）；fxri-* skills = AI 侧可变细节唯一演进源（升级走 `skills update` 自动扩散）；ai-rules.md = 薄壳稳定纪律 + 对 skills 的引用。能力升级只改 skills 一层，操作手册与全局规则不随每次升级反复维护
  - 来源：20260906-唐启云-新增操作手册与全局规则薄壳
- **规则细节只进 skills**：可变流程细节禁止在 ai-rules.md 等规则层复述（AGENTS.md 质量门第 5 条已固化），防止能力升级后用户侧规则快照失同步
  - 来源：20260906-唐启云-新增操作手册与全局规则薄壳
