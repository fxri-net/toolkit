# 项目协作规范（conventions）

> 本载体为「规范溯源簿」：记录本项目确立的每条规则、适用面（归属）、确立时的来源任务、演进历史，以及条文的单一事实源位置。条文内容一律以各单一事实源最新版为准（skills / task-spec / ai-rules / AGENTS），本载体不复制条文，避免版本漂移。
> 非任务文件，`toolkit tasks` 不读取内容、`check` 不告警。由任务归档（任务级）与会话收尾（会话级）维护，写入前经用户确认。载体结构、端名规则、读写判定与存量迁移见 `skills/fxri-plan-to-task/references/conventions-spec.md`。

## 四、用法说明

- 本项目已具备完整规则层（AGENTS.md 治理 + ai-rules 全局规则 + skills 流程），故本载体采用**溯源索引式**：不复制条文，只记「确立了什么、适用哪个端、谁确立的、条文去哪看」。
- 无其他规则文件的项目可选用**条文式**：条文全文写入对应归属分册（`common.md` / `<端名>.md`），本载体即项目唯一规范载体。两式可混用，差异见 `conventions-spec.md` 第 7 节。
- 读取分层：常驻只读本文件（端清单 + 索引）；按任务 `scope` 命中端分册并叠加 `common.md`。本项目单端无分册，读本文件即全貌。
- 规则层源头变更时：修改 `AGENTS.md` / `docs/ai-rules.md` / skills 条文的变更须同步检查本表对应行（当前语义是否需要更新），随该变更同批落盘；语义变更须先在「演进记录」留痕，再更新表内当前语义。
