# 问答页去冗余压缩

> 计划位置：第 2 个（共 5 个）；前置：20261108-唐启云-可读性门禁补测与口径留痕；后继：20261108-唐启云-技能分发页下沉收敛

延续 指南问答页拆句（见 archive/202611/20261108.md）

## 背景

`docs/faq.md` 现为 278 行 / 10,237 字符，超出 `C-40` 的 250 行建议值 28 行。本页定位是「问题 → 答案」，
同一事实只在真源页维护一次，因此压缩方向不是再拆句，而是**去冗余**：把与快速开始 / 完整攻略重复的展开收成一句 + 指针。

## 实施方案

1. 按「一个问答一个结论 + 最少必要条件」逐条过：结论、命令、链接保留，重复解释指向真源（不新增链接，优先复用已有链接）。
2. 重点压缩三处：
   - 「个人用，全局装还是每个项目里装」：升级命令与诚实代价两段合成一段，保留全部事实
   - 「任务做完必须提交、发版、推送吗」：顺序约束与动作边界合并，去掉与 `docs/guide.md` 重复的解释
   - 「卸载工具时 skills 怎么办」：三条并列改为一句 + 一条 ⚠️
3. 保持 33 个 `###` 标题与锚点不变（外部链接依赖），删除内容只限重复表述，不删任何事实、命令与限制条件。
4. 行数目标 ≤250，字符同步下降；改后 `node scripts/check-docs-readability.mjs` 必须为 0。

## 影响范围

- 文档触达：docs/faq.md
- 不触达其他页面：不新增、不删除链接目标，锚点不变
- 不建变更集：`docs/` 不随包分发

## 验证方式

1. `docs/faq.md` 行数 ≤250、字符数下降
2. `node scripts/check-docs-readability.mjs` 全仓 0 处超标
3. `pnpm docs:build` 通过（跨页链接与锚点）
4. `pnpm verify` 全绿
