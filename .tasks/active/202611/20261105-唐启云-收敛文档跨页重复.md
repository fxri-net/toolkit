# 收敛文档跨页重复内容

## 背景

体检发现 5 组页面重复度偏高：`faq ↔ guide` 0.151、`faq ↔ handbook` 0.148、`cli ↔ guide` 0.136、`getting-started ↔ handbook` 0.133、`guide ↔ handbook` 0.128。主要是安装命令、技能安装、任务区说明、发版流程在多页各写一遍，改一处要同步多处。

## 实施方案

1. 建重复段落清单：逐组列出「段落主题 / 出现页面 / 当前表述差异」。
2. 每组定唯一真源：安装与最短路径 → `getting-started`；完整工作流 → `guide`；命令契约 → `cli`；分场景操作 → `handbook`；`faq` 只答差异并指回真源。
3. 非真源页改为 1–2 行指针 + 该页特有差异说明，不整段复述。
4. 复核改动后各页重复度下降（对照组：faq↔guide、guide↔handbook 目标 < 0.08）。

## 影响范围

- 文档：`docs/faq.md`、`docs/handbook.md`、`docs/getting-started.md`、`docs/guide.md`、`docs/cli.md`（仅指针）。
- 变更集：patch。

- 文档触达：docs/faq.md、docs/handbook.md、docs/getting-started.md、docs/guide.md、docs/cli.md

## 验证方式

- 重复段落清单逐组核对「真源唯一、其余为指针」。
- 重复度指标下降；站内链接可解析；`pnpm verify` 全绿。
