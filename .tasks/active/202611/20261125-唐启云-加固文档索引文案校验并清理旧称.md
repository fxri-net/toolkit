# 加固文档索引文案校验并清理旧称

> 计划位置：第 3 个（共 3 个）；前置：20261125-唐启云-统一规则页标题与站内引用、20261125-唐启云-统一README与文档索引名称；后继：无

## 背景

`scripts/check-consistency.mjs` 的「索引文案 == 目标页标题」只覆盖 `docs/config.md` 的配置分页表；`README.md` 与 `docs/index.md` 的文档索引只校验页面集合与行序，不校验文案，`docs/rules/index.md` 的规则表也不在校验范围。因此 2026-11-24 的页面改名漏掉 README 后，现有门禁全部通过。

本任务只加结构性一致性校验（索引文案等于目标页标题），不引入旧词黑名单。

## 实施方案

1. `scripts/check-consistency.mjs`：把「索引文案 == 目标页标题」扩到 `README.md` 与 `docs/index.md` 的文档索引表、`docs/rules/index.md` 的整篇规则表；外链跳过，目标页解析沿用既有 `resolveDocPage` / `pageTitle`。
2. `src/__tests__/consistency-references.test.ts`：补假现场用例——README 索引文案与目标页标题不一致时报 error、规则表文案不一致时报 error、一致时通过。
3. `src/__tests__/docs-diagrams.test.ts`：L1 与 L22 的「核心模型页」改为「一图看懂页」。

## 影响范围

- 触达：scripts/check-consistency.mjs、src/__tests__/consistency-references.test.ts、src/__tests__/docs-diagrams.test.ts
- 变更集：无（只改仓库自检与测试，不改 CLI 对外行为）

## 验证方式

1. 新增假现场用例覆盖合规通过、违规报出两条路径。
2. `pnpm verify` 全绿。
3. 跑一次全量校验，确认前两个任务的文案改动未残留可被新校验检出的不一致。
