# 技能简介解析与交互展示

> 计划位置：第 3 个（共 4 个）；前置：无；后继：20261123-唐启云-技能列表与简介落账

## 背景

安装 / 卸载的技能多选只显示英文名，用户看不出每个技能做什么；`PackageSkill` 目前只解析 `name / version / tier / requires / previousNames / gate`，
`SKILL.md` 的 `description` 没有进入类型，因此任何界面都拿不到简介。

## 实施方案

1. `src/skills/source/*` 解析 frontmatter `description` 到 `PackageSkill.description`；同时生成 `summary`：取首句、去 Markdown 标记、按显示宽度截到 72 列（中文按 2 列计），超出补 `…`。
2. 交互多选每项两行展示：第一行技能名（保留 `[必装]` 等既有标记），第二行缩进灰字简介；窄窗按可用宽度再截断；非 TTY 不打印简介。
3. 新增 `src/skills/format.ts` 统一行格式（名称 / 简介 / 版本 / 形态），供 `install`、`uninstall`、`mount`、`source list` 复用，避免各处长度与措辞漂移。
4. `--format json` 契约不变（简介只进人读层）；`NO_COLOR` 下灰字降级为普通文本。
5. 文档：`docs/cli/skill.md` 说明选择列表新增简介行与截断口径。

## 影响范围

- 代码：`src/skills/source/*`、`src/skills/types.ts`、`src/skills/prompt.ts`、`src/skills/format.ts`（新）、`src/cli-ui.ts`（多选第二行）
- 测试：`src/__tests__/skills-summary.test.ts`（新，CJK 宽度与截断）、`cli-golden` 快照
- 文档触达：docs/cli/skill.md
  - 已同步（选择列表两行展示与截断口径）
- skills 触达：无（只改展示，不改技能内容）
- 变更集：patch

## 验证方式

- 单测覆盖：中文 / 英文 / 混排按宽度截断、无 description 时的占位、窄窗边界
- grep 全部序列化点（`--format json` 输出），确认 `description` / `summary` 只进人读层、未改变既有 JSON 契约
- golden 快照更新并复核只有简介行变化
- `pnpm verify` 全绿；`node dist/cli.js task check` error 0 / warn 0

## 回滚

移除简介行渲染与 `summary` 生成即可；`description` 字段保留无害。
