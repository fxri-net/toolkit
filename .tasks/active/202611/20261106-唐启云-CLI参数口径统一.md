# CLI 参数与语义口径统一

## 计划位置

toolkit 2 / 5；前置：CLI 命名收敛；目标版本：1.16.2。

## 背景

同一类参数在不同域有三到四种写法：布尔开关混用 `on|off` 取值、`--flag/--no-flag` 与 `enable/disable` 子命令；时长参数混用 `--older-than 30`（裸数字）与 `--since 30d`；`--format` 在多数命令指 stdout、在 `usage export/import` 指文件格式；`--yes` 在 `skills install` 表示「接受已保存选择」，在 `usage` 表示「非交互」。

## 实施方案

1. **布尔开关**：`usage origins`（原 `sources`）与 `usage capture` 由 `--x <on|off>` 改为 `--x` / `--no-x` 成对开关；`usage enable/disable` 保留为域总开关。
2. **时长语法**：`usage purge --older-than` 只接受 `30d` / `24h` / `60m`，与 `--since` 同一解析器；裸数字按非法值报错退出，不保留旧写法。
3. **预演**：`usage uninstall` 补 `--dry-run`（只预览将停用的配置与将移除的 Hook，不写盘）；其余写盘命令逐条核对预演覆盖。
4. **全量约定**：目标集合是主语时省略参数即全部（如 `skills sources refresh`），否则必须显式 `--all`；在 `docs/cli.md` 固化该规则。
5. **清理词**：`usage uninstall --purge-data` 更名为 `--purge`；`--prune` 专用于清理未选中产物（skills 域）；`purge` 子命令专用于删除数据。
6. **格式参数**：`usage export` / `usage import` 的 `--format` 更名为 `--type`；`--format` 只用于 stdout（目前仅 `json`）。
7. **确认参数**：`skills install --yes` 拆为 `--yes`（跳过确认）与 `--use-saved`（接受已保存选择）；`skills bump`、`usage init/uninstall` 的 `--yes` 语义不变。
8. **诊断语义与退出码**：固化 `status/info` 恒 0、`check` 发现问题非 0、`doctor` 恒 0；在 `docs/cli.md` 与各命令帮助中写明，不改现有命令行为。
9. **不提供兼容层**：被移除的旧命令、旧参数与旧取值一律不保留别名、不做双写法兼容。
10. 本任务新增变更集，`patch`，逐条以 `- 修改：` 书写。

## 影响范围

- 代码：`src/usage/commands.ts`（解析与帮助）、`src/cli.ts`（skills install/bump 选项）、`src/usage/wizard.ts`（uninstall 预演）、`src/usage/stats.ts`（时长解析复用）。
- 测试：`src/__tests__/usage-cli.test.ts`、`usage.test.ts`，以及 skills install 选项相关用例。
- 文档触达：docs/cli.md、docs/cli/usage.md、docs/cli/skills.md、docs/cli/tasks.md、docs/cli/conventions.md、docs/cli/docs-theme.md、docs/usage/configuration.md、docs/config/skills.md、docs/config/update.md、docs/guide.md、docs/handbook.md
- 无触达：`skills/`（未引用被改参数）、`AGENTS.md`、`SPEC.md`、`docs/ai-rules.md`。

## 验证与回滚

- `pnpm verify` 全绿；手工抽查 `usage origins --no-first-party`、`usage capture --no-trigger`、`usage purge --older-than 30d --dry-run`、`usage uninstall --dry-run`、`usage export --type csv`。
- 非法取值仍按「降级不静默」告警并退出非 0。
- 回滚：单任务单提交，`git revert` 即可。
