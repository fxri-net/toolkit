# 拆分 usage 命令模块

> 计划位置：第 7 个（共 10 个）；前置：20261112-唐启云-拆分 skills 安装模块；后继：20261112-唐启云-拆分 tasks 校验模块

## 背景

`src/usage/commands.ts` 995 行，把 usage 域全部子命令（配置开关、统计查询、导出导入、初始化向导、Hook 管理、doctor、上传、规则输出）与各自的参数解析、打印函数放在同一文件。该文件已用 `registerUsageCommands(program)` 自注册，是本轮重构的目标形态，但其内部粒度仍过粗。

## 实施方案

1. 拆为 `src/usage/cli/`：
   - `context.ts`：`UsageContext`、`createContext`、`printJson`、`formatLocalTime`、`parseOlderThanDays`、`parseSource`、`SOURCE_VALUES` 等共用助手；
   - `config.ts`：usage config 子命令；
   - `stats.ts`：stats / list / unused 等查询类子命令；
   - `export.ts`：导出与导入子命令；
   - `init.ts`：初始化向导与 Hook 安装卸载入口；
   - `doctor.ts`：doctor 子命令；
   - `upload.ts`：上传配置与状态子命令（只做命令层，网络实现仍在 `src/usage/upload.ts`）；
   - `rule.ts`：`usage rule` 子命令。
2. `src/usage/commands.ts` 保留为 barrel 或改为汇总注册入口（`registerUsageCommands` 内部按序调用各子模块注册函数）。
3. ⚠️ **`src/usage/upload.ts` 必须留在原位、文件名不变**：`src/__tests__/usage-upload.test.ts` 的「除 upload.ts 外不出现网络调用」静态扫描按文件名豁免，移动或改名会让该用例失准。
4. 子命令注册顺序保持不变，保证 `toolkit usage --help` 输出顺序一致。

## 影响范围

- 新增：`src/usage/cli/` 下 8 个文件。
- 修改：`src/usage/commands.ts`（收缩为注册入口）、`src/usage/index.ts`（如有导出路径调整）。
- 文档影响：无（`docs/cli/usage.md` 描述行为，本次不变）。
- 变更集：patch 一条（优化：usage 命令按子命令拆分模块）。

## 验证方式

- `pnpm vitest run src/__tests__/usage.test.ts src/__tests__/usage-cli.test.ts src/__tests__/usage-upload.test.ts src/__tests__/usage-hooks.test.ts src/__tests__/usage-record.test.ts src/__tests__/stats.test.ts`：全绿。
- `pnpm vitest run src/__tests__/cli-golden.test.ts`：快照 0 diff。
- `pnpm verify` 全量通过。
