# 产物与 guard 按目录矩阵

> 计划位置：第 2 个（共 4 个）；前置：20261123-唐启云-形态并入策略解析；后继：20261123-唐启云-作用域写命令联动产物

## 背景

策略统一后，形态是「技能 × 目录」矩阵。产物仍只有一份全局技能目录，需要明确：哪些技能装全文、哪些装入口壳，guard 如何按当前目录返回正文。

## 实施方案

1. 产物判定：逐技能汇总所有可命中规则——**全部目录都是 full** 时装全文；**任一目录为 gated 或 off** 时装全局入口壳。
2. `scope guard` 按当前目录解析形态：
   - `full` → 输出正文；
   - `gated` → 生效目录输出正文，其余空；
   - `off` → 空；
   - 保持现有退出码：未激活退出码 3，成功 0。
3. `skill install` / `skill plan` / `skill status` 改用矩阵：只收敛需要入口壳的技能，全文技能不动；`off` 残留由 `--prune` 清理。
4. 性能（需可测）：
   - 只有含非 full 规则的技能才装入口壳，全 full 技能不产生 guard 调用；
   - 引导同一技能同会话复用 guard 结果，避免重复启动；验收时记录「每技能首次 guard」耗时，确认没有按消息重复调用；
   - 需要零 guard 开销的高频技能，文档给项目面安装路径（`--scope project` / `skill mount`）。
5. 测试：全 full 技能保持全文；任一 gated 技能装壳；guard 在 full / gated / off 三类目录的行为；`skill status` 计数与残留提示。
