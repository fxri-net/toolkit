# 分发清单表格化与重复段落收敛

> 计划位置：第 3 个（共 7 个）；前置：20261108-唐启云-文档可读性门禁；后继：20261108-唐启云-命令参考页拆句

## 背景

两份枚举被内联进句子，是「读不动」的主要来源之一：

1. **19 个项目级技能候选目录**：现在 3 处内联——`docs/cli/skills.md` L154、`skills/README.md` L43、`skills/fxri-plan-to-task/references/conventions-spec.md` L51。每处都是一串「目录（agent 名）」挤在同一句里，`conventions-spec.md` 那段因此长到 1315 字符。
2. **10 家 canonical 共读 agent**：3 处内联——`docs/cli/skills.md` L168、`skills/README.md` L39、`docs/guide.md` L174。

计划表原写「收敛为表格真源 + 其余改指针」，实施前复核发现指针方案不可行，改为**格式归一**：`skills/` 与根 `README.md`/`SPEC.md` 随 npm 包分发，`docs/` 不在 `package.json` 的 `files` 白名单内，因此 `skills/README.md` 指不到 `docs/` 页面、`conventions-spec.md` 还要被复制进用户项目、更无页可指。保留三份、三份都改成表格（可扫读），一致性继续靠改动时的全仓 grep 与「文档触达」登记流程。

同时收敛重复叙述：`docs/cli/skills.md`、`skills/README.md`、`docs/guide.md` 各讲了一遍「全局面三层目标 / 项目面薄壳」，本任务只压掉其中重复展开的细节、保留各页视角所需的最短版本，不做跨页指针。

## 实施方案

1. `docs/cli/skills.md`「作用域」节：把 19 个候选目录从句子移出，改为「目录 | agent」两列表格（按 agent 分组）；`.cursor/skills/`、`.trae-cn/skills/` 的排除说明保留为表下一行；L168 的 10 家共读 agent 名单同样改表格「agent | 说明」或一行分组列表。
2. `skills/README.md`：同一清单改同形表格；L39 的共读名单改列表。
3. `skills/fxri-plan-to-task/references/conventions-spec.md`：L51 拆为「入口壳机制」段落 + 候选目录表格；机制部分的括号嵌套改为子项列表。
4. `docs/guide.md` L174：只保留主目标与三层顺序的一句话结论，明细指向 `docs/cli/skills.md#作用域`（同在 `docs/`，相对链接可用）。
5. `skills/fxri-plan-to-task` 内容变更 → 版本递增 `1.10.2` → `1.10.3`，两处写位同步：`SKILL.md` frontmatter `metadata.version` 与正文首行「本技能版本」；两张技能表（`skills/README.md`、`docs/guide.md`）版本列同步。
6. 建变更集：`.changeset/` 一条 patch，条目写 `- 文档：…`（skills 内容随包分发，属用户可感知变更）。

## 影响范围

- 文档触达：docs/cli/skills.md、skills/README.md、docs/guide.md、skills/fxri-plan-to-task/references/conventions-spec.md、skills/fxri-plan-to-task/SKILL.md
- 变更集：`.changeset/` 新增 patch 条目
- 不改代码：目录清单与代码常量（`src/skills/types.ts`）保持现状，本任务只改呈现形态
- `check-consistency.mjs` 三项校验须仍通过：技能版本四点一致、技能表用途列片段存在于 SKILL、触达路径存在

## 验证方式

1. `node scripts/check-consistency.mjs` 无 error / warn（版本四点一致）
2. `node scripts/check-docs-readability.mjs` 通过，且这三个文件在基线中的余量下降（必要时同步下调基线数值）
3. `grep -rn "windsurf/skills"` 与 `grep -rn "Kimi Code CLI"` 确认三处形态一致、无句子内联残留
4. `pnpm verify` 全绿
