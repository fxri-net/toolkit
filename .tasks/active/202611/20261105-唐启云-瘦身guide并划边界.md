# 瘦身 guide 并划清与 handbook 的边界

## 背景

`docs/guide.md` 327 行 / 19.5k 字符，超过拟定的单页阈值（250 行 / 12k）；12 节混装工作流、任务文件规范、技能包、CHANGELOG、部署等内容，与 `cli.md`（重复度 0.136）、`faq.md`（0.151）重叠；「Git 纳管范围」夹在任务规范与方案落盘之间。`handbook.md`（167 行 / 7.3k）与它是「完整攻略 vs 实践手册」的关系，但内容互渗。

## 实施方案

1. 建「章节 → 保留 / 下沉 / 迁出」映射表：完整流程留 guide；命令参数指向 `cli`；任务文件细则指向技能包 `task-spec`；分场景步骤归 handbook。
2. 调整章节顺序：工作流总览 → 任务文件规范 → 方案落盘 → Git 纳管 → 会话沉淀 / 恢复 → 技能包 → 发版与 CHANGELOG → 文档站部署 → 升级与版本兼容。
3. 体量压到 250 行 / 12k 以内；超出部分改为指针。
4. 与 `handbook.md` 的边界写进两页开头（各一句「本篇讲什么、不讲什么」）。

## 影响范围

- 文档：`docs/guide.md`、`docs/handbook.md`（仅边界句与必要指针）、受影响锚点链接。
- 变更集：patch。

- 文档触达：docs/guide.md、docs/handbook.md

## 验证方式

- 规模达标；两页开头边界句互不矛盾；站内链接可解析。
- `pnpm verify` 全绿（含文档站构建）。
