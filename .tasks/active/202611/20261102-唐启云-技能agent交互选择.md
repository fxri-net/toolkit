# 技能 agent 交互选择

批次：技能管理架构　计划位置：2　前置：任务 1

## 背景

当前安装器默认写入所有检测到的 agent 目录，装了多个 agent 的机器会产生大量目录与状态噪音。需要在技能选择之后增加方向键 agent 多选，并持久化长期选择；取消 agent 时保留已安装产物，由用户确认或 `--prune` 清理。

## 实施方案

1. `prompt.ts`：基于 `@inquirer/prompts` 的 checkbox/confirm 实现方向键多选；分组显示 canonical、已检测 agent、自定义目录；canonical 标注共读覆盖范围；不可用 agent 置灰；方向键 / 空格 / 回车 / Ctrl+C 取消。
2. 配置：`skillsInstall.targets` 存全局 agent name；`projectSkills.targets` 存项目候选目录相对路径；`--agent` / `--all-agents` 显式指定时更新长期选择，`--no-save-agents` 只影响本次；`--dir` 始终一次性。
3. 交互流程：技能选择 → agent 选择 → 汇总确认；只有一个可用目标时跳过 agent 选择；确认前 Ctrl+C 不写任何文件。
4. 取消 agent：交互默认保留已安装产物，提示可 `--prune` 清理；非交互保留，`--prune` 才删；第三方 / 本地修改产物永不自动删；状态标记 `installed-unselected`，不计入 problems。
5. 项目面：交互列出已存在的项目候选目录，保存相对路径到 `.toolkit/state.json`；`prepare` 非交互按已保存选择刷新，不新增未选择目录。
6. 文档与变更集：更新 `docs/cli.md`、`docs/guide.md`、`README.md`；在任务 1 的变更集中追加 agent 选择条目。

## 验证方式

- `pnpm verify` 全量通过；`tasks check` 双零。
- 手工矩阵：首次全选、取消 A 保留、`--prune` 清理、重新选择 A 恢复；`--agent` 更新长期选择、`--no-save-agents` 不更新；项目面目录选择与 `prepare`。
- 非 TTY / `--yes` 不弹窗，按保存选择执行。

## 回滚方案

`git revert` 本任务提交；已保存的 targets 可手工删回上一条选择；产物清理失败不影响其他目标。
