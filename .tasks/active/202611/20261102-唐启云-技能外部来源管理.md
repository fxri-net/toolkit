# 技能外部来源管理

批次：技能管理架构　计划位置：3　前置：任务 1

## 背景

playbook 是独立技能内容仓，toolkit 当前只能安装自身包内 `skills/`。需要增加通用 `--from` 来源能力，让任意符合技能源格式的目录可被同一套 tier / 选择 / 状态 / prune 管理，同时保持 toolkit 不出现 playbook 具体名字。

## 实施方案

1. `source.ts`：解析内置 `toolkit` 源与 `--from` 本地源；支持根 `SKILL.md` 单技能、`skills/*/SKILL.md` 多技能、`skills.json` manifest；`formatVersion` 校验；路径 / 符号链接越界拒绝；同名技能跨源报错。
2. 来源登记：`--from <src>` 默认临时，只写状态；`--save [name]` 永久登记到 `skillsInstall.sources`，name 可省略并按目录 / 包 / 仓库名派生，冲突报错。
3. 产物形态：内置源保持软链；永久外部源默认软链到来源根，失败降级副本；临时外部源直接副本；`--copy` 可强制副本。
4. 多源状态：`sources` 对象按来源分组，target 内 entries 记录 `name/version/mode`；`status` 按来源分组；`remove --source` / `sources remove --prune` 清理；临时来源可单列清理。
5. 锁：新增 `lock.ts`，全局 `~/.agents/.toolkit-skills.lock`、项目 `.toolkit/skills.lock`；5 分钟过期；记录 PID/host/startedAt；`try/finally` 释放。
6. 写入顺序：install 产物 → 状态 → 配置；remove 配置 → 产物 → 状态；状态 / 配置原子写。
7. 文档与变更集：更新 `docs/cli.md`、`docs/config.md`、`docs/guide.md`、`README.md`；在变更集中追加 `--from` 条目。

## 验证方式

- `pnpm verify` 全量通过；`tasks check` 双零。
- 手工矩阵：单技能源、多技能源、有 / 无 manifest、临时 / 永久、`--save` 派生名与冲突、跨源同名报错、`--prune`、锁冲突与过期接管、符号链接越界拒绝。
- 用本地目录模拟 playbook，不依赖真实 playbook 仓。

## 回滚方案

`git revert` 本任务提交；临时来源状态可 `remove --source` 清理；永久来源登记可 `sources remove` 注销。
