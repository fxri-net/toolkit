# tasks 域真子命令化

## 计划位置

toolkit 3 / 5；前置：CLI 参数与语义口径统一；目标版本：1.16.2。

## 背景

`tasks` 目前用单个 `[command]` 位置参数加白名单手写分派（`archive` / `check` / `normalize` / `stats`），导致 `tasks archive --help` 打印的是组帮助，子命令没有独立选项说明；同时动作能力被拆成组级标志（`--export`、`--import`、`--check`、`--fix`），与 `usage` 域的子命令形态不一致。

## 实施方案

1. 把 `archive` / `check` / `normalize` / `stats` / `export` / `import` 注册为真正的 Commander 子命令；`tasks` 裸命令保留为总览（现有过滤参数继续留在组级）。
2. 选项下沉：`--fix` / `--check` 归 `tasks normalize`；`--export` 归 `tasks export`；`--import` / `--target` 归 `tasks import`；`--dry-run` 按子命令各自声明；`--dir` 保留在组级。
3. 删除组级 `--check` / `--fix` / `--export` / `--import`，消除 `tasks check`（校验）与 `tasks --check`（归一化检查）同词不同义。
4. 子命令帮助、非法参数提示、退出码与现行为保持一致；`tasks check` 仍作为 `pnpm verify` 的门禁步骤。
5. **不提供兼容层**：组级 `--check` / `--fix` / `--export` / `--import` 直接移除，不保留旧写法与别名。
6. 同步改写 `docs/cli/tasks.md`、`docs/config/check-tasks.md` 与各指南中的命令示例；新增变更集，`patch`。

## 影响范围

- 代码：`src/cli.ts`（tasks 域注册与分派）、`src/tasks/*` 中依赖组级选项的入口签名。
- 测试：`src/__tests__/tasks*.test.ts`、`roundtrip.test.ts`、`repo-guard` 相关用例中的 CLI 调用串。
- 文档触达：docs/cli/tasks.md、docs/config/check-tasks.md、docs/cli.md、docs/guide.md、docs/handbook.md、docs/getting-started.md、docs/faq.md、docs/index.md
- skills：`fxri-plan-to-task` / `fxri-session-recap` 中使用的 `tasks archive/check/normalize/stats` 命令名不变，`--fix` 已是子命令写法，无需改技能，版本不动。
- 无触达：`AGENTS.md`（只写 `toolkit tasks check`，命令名不变）、`docs/ai-rules.md`。

## 验证与回滚

- `pnpm verify` 全绿，重点确认 `toolkit tasks check`、`tasks normalize`、`tasks archive`、`tasks export/import` 的子命令帮助可独立输出。
- 手工抽查：`toolkit tasks archive --help` 应显示 archive 自己的选项。
- 回滚：单任务单提交，`git revert` 即可。
