# 门禁补强Node基线与交互约束

> 计划位置：第 2 个（共 4 个）；前置：20261121-唐启云-命名规范与fx前缀规则；后继：20261121-唐启云-环境变量前缀收编FX

## 背景

两处规则目前只有文字、没有门禁，属「纸面规则」：

- 运行时兼容：`engines` 为 `>=18.17.0`、`@types/node` 为 18，但没有任何检查阻止新代码使用仅 Node 20+ 可用的 API（`Array.fromAsync`、`Object.groupBy`、`Promise.withResolvers` 等），最低版本兼容只能靠人工记忆
- 交互入口：交互能力已收敛到 `src/prompts.ts`，但没有检查阻止其他文件直接 `import "@inquirer/prompts"`，统一层随时可能被绕过

按既有纪律「规则落门禁」，本任务把两条规则同时补上检测入口。

## 实施方案

1. `eslint.config.mjs` 增加运行时兼容检查：
   - 用 `no-restricted-syntax` 禁用 Node 20+ 才稳定的标识符与成员：`Array.fromAsync`、`Object.groupBy`、`Map.groupBy`、`Promise.withResolvers`、数组的 `toSorted` / `toReversed` / `toSpliced` / `with`、字符串的 `isWellFormed` / `toWellFormed`
   - 违规提示写明「以 package.json 的 engines 为基线，最低版本须可运行」
2. `eslint.config.mjs` 增加交互入口约束：
   - `no-restricted-imports` 禁止 `@inquirer/prompts`，提示「交互一律走 src/prompts.ts」
   - 用 override 对 `src/prompts.ts` 放行（该文件是唯一合法引入点）
3. `.tasks/conventions/platform.md` 增加 `## C-46. 运行时版本基线`（通用措辞：以 `engines` 为唯一基线；只用基线已稳定、无实验标记的 API 与语法；引入较新 API 前核对版本支持表；最低支持版本须有可执行的 CI 回归入口、随版本升级保持有效；不得为省事使用仅高版本可用的内置）
4. `.tasks/conventions/index.md` 增加 `C-46` 行；`history.md` 追加一行。
5. 文档：`docs/guide.md` 的环境要求段与 `docs/faq.md` 的版本门槛段核对，补一句「只使用基线已稳定的 API」（已有等价表述则不重复）。
6. CI 现状核对：`ci.yml` 已有 `node18` 冒烟 job（Node 18.17.0 + `scripts/smoke-node18.mjs`），本任务不新增 job；若禁用清单后续扩充到冒烟脚本未覆盖的 API，须同步补一条最小调用。

## 影响范围

- 代码：`eslint.config.mjs`
- 文档触达：docs/guide.md、docs/faq.md
- 规范载体：`.tasks/conventions/platform.md`、`index.md`、`history.md`
- 无触达：`docs/config/*`、`docs/cli/*`（不涉及命令参数与退出码）；`README.md`（不描述运行时 API 约束）
- skills：无触达

## 验证方式

- `pnpm lint`：全仓通过
- 违例反证：临时写入一个使用 `Promise.withResolvers` 的文件与一个直接引 `@inquirer/prompts` 的文件，确认 lint 报错后删除
- 放行反证：`src/prompts.ts` 引 inquirer 不被拦截
- `pnpm verify`：全量门禁通过

## 回滚

单次提交可整体 `git revert`；回退后两条规则恢复为纯文字约定，eslint 配置与规范条目同批回退。不发版、不推送。
