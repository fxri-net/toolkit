# 矩阵视图与旧配置迁移

> 计划位置：第 4 个（共 4 个）；前置：20261123-唐启云-作用域写命令联动产物；后继：无

## 背景

矩阵能力落地后，需要可解释的视图与旧配置迁移，否则用户无法确认「某技能在某目录为什么是 gated / full / off」。

## 实施方案

1. `skill status --matrix [--at <目录>]`：输出技能 × 目录（或目录组）的形态矩阵、命中规则与被压规则；支持 `--format json`。
2. `skill plan --at <目录>` 与 `scope status --skills --at <目录>` 复用同一解析器，显示当前目录下的形态依据。
3. 旧配置迁移：
   - `skillDelivery.rules` 读取时编译为带 `when: {}` 的策略，origin 规则级、优先级高于手写 policies，行为不变；提示后续可直接写 `policies.delivery`；
   - `activation.skills` 继续兼容，矩阵视图标注「由旧字段编译」；
   - 新旧配置并存时按「rules > policies > default」解释，`skill status --matrix` 显示每一层的取值来源；
   - `toolkit status` 检测到旧字段时给一次迁移提示，不自动改写。
4. 文档与 help：新增矩阵示例（A 全 gated、B 子集 gated、其余 full/off）、优先级与默认值、性能建议（同会话复用、项目面安装）。
5. 变更集 patch；golden 快照同步。

## 影响范围

- 代码：`src/commands/skill.ts`、`src/commands/scope.ts`、`src/skills/status.ts`、`src/scope/load.ts`、`src/status.ts`
- 测试：`skills-status`、`scope-*`、`cli-golden`
- 文档触达：docs/cli/skill.md、docs/cli/scope.md、docs/config/activation.md、docs/config/skill.md、docs/faq.md
  - 五篇均已同步（矩阵视图、优先级来源、旧配置迁移提示）
- skills 触达：无（`skill status` 仅被技能泛引，未描述视图字段）
- 变更集：patch（按用户口径，矩阵视图视为设计缺陷修复）

## 验证方式

- 矩阵视图在 A/B/C 三类目录的文本与 JSON 输出正确
- 旧配置读取结论与升级前一致；迁移提示只出现一次
- `pnpm verify` 全绿；`node dist/cli.js task check` error 0 / warn 0

## 回滚

删除矩阵视图命令与迁移提示，保留解析器；旧配置仍按原语义读取。
