# 查询与二级动作收敛

## 计划位置

toolkit 5 / 5；前置：CLI 参数与语义口径统一；目标版本：1.16.2。

## 背景

查询与二级动作存在多个平级变体：`usage stats` / `top` / `sessions` / `triggers` 四个命令参数各不相同；`usage upload` 同时有子命令 `setup/status` 与动作标志 `--once/--dry-run/--limit`；`docs theme --check/--write` 用标志表达动作；`skills sources notify <name> <frequency>` 用位置参数设值，与其余设置类命令的 flag 风格不一致。

## 实施方案

1. `usage stats` 合并查询维度：新增 `--by skill|session|trigger`（默认 `skill`）、`--limit`、`--skill`、`--agent`、`--source`、`--since`、`--unused`；删除 `usage top` / `sessions` / `triggers`。
2. `usage upload` 动作子命令化：`upload --once` → `upload send`，`--dry-run` / `--limit` 归 `upload send`；`upload setup` / `upload status` 保留。
3. `docs theme` 动作子命令化：`--check` → `docs theme check`（默认动作），`--write` → `docs theme write`，`--force` 归 `write`。
4. `skills sources notify` 的频率改为 `--frequency always|daily|weekly|off`，来源名保留位置参数。
5. **不提供兼容层**：`top` / `sessions` / `triggers`、`upload --once`、`docs theme --check/--write`、`notify` 的位置参数取值一律移除，不保留别名。
6. 同步命令页、总览页与指南中的示例；新增变更集，`patch`。

## 影响范围

- 代码：`src/usage/commands.ts`（stats/upload）、`src/usage/stats.ts`（聚合入口）、`src/cli.ts`（docs theme、skills sources notify）。
- 测试：`src/__tests__/usage-cli.test.ts`、`usage.test.ts`、`docs-theme` 相关用例、skills sources 相关用例。
- 文档触达：docs/cli/usage.md、docs/usage/index.md、docs/usage/privacy.md、docs/cli/docs-theme.md、docs/cli/skills.md、docs/config/skills.md、docs/cli.md、docs/handbook.md、docs/guide.md
- 无触达：`skills/`（未引用被改命令）、`AGENTS.md`、`SPEC.md`、`docs/ai-rules.md`、`.tasks/conventions`。

## 验证与回滚

- `pnpm verify` 全绿；手工抽查 `usage stats --by session`、`usage stats --by trigger --skill fxri-plan-to-task`、`usage upload send --dry-run`、`docs theme check`、`docs theme write`、`skills sources notify <name> --frequency weekly`。
- 旧命令 `usage top` / `sessions` / `triggers` 报未知命令并非 0 退出。
- 回滚：单任务单提交，`git revert` 即可。
