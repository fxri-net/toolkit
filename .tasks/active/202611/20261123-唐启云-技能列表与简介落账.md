# 技能列表与简介落账

> 计划位置：第 4 个（共 4 个）；前置：20261123-唐启云-技能简介解析与交互展示；后继：无

## 背景

用户想随时查看「装了哪些技能、各自做什么」，现在只能从 `skill status` 的多目录现场里逐条找，且状态文件只登记 name / version / mode，
技能来源不可用时简介就无从获取。

## 实施方案

1. 新增 `toolkit skill list [--installed|--all] [--format json]`：默认列出已装技能，每行「名称 · 简介 · 版本 · 形态 · 目标数」；
   `--all` 含未安装；形态按当前目录解析（与 `install` 同口径），不提供 `--at`，目录级排查仍走 `skill status --matrix --at`。
2. 状态文件条目增加 `summary`：`install` 成功时写入截断简介；旧账缺失时现场解析回填，下次 `install` 落盘；
   state 读取保持向后兼容（缺字段不报错）。
3. 来源不可解析时简介回落 `summary`，仍缺失显示 `—` 并在末尾提示「来源不可用，可重跑 toolkit skill install 刷新」；
   `--all` 且来源不可用时只列已装技能并明确说明，不输出空列表假装没有技能。
4. 文档：`docs/cli/skill.md` 增加 `skill list` 示例与 JSON 字段；`docs/config/skill.md` 说明状态文件新增 `summary` 字段。

## 影响范围

- 代码：`src/commands/skill.ts`、`src/skills/list.ts`（新）、`src/skills/state.ts`、`src/skills/types.ts`、`src/skills/format.ts`、`src/skills/install/*`（写入 `summary`）、`src/command-registry.ts`
- 测试：`src/__tests__/skills-list.test.ts`（新）、`skills-selection.test.ts`（state 兼容）、`command-registry.test.ts`、`cli-golden` 快照
- 文档触达：docs/cli/skill.md、docs/config/skill.md
  - 两篇均已同步（命令示例、JSON 字段、状态文件 `summary` 与旧账兼容）
- skills 触达：无（技能未描述该命令的字段细节）
- 变更集：patch

## 验证方式

- 单测：已装 / 未装 / 来源不可用三类输出；旧 state 无 `summary` 时不报错且能回填
- `--format json` 字段稳定；golden 快照同步
- `pnpm verify` 全绿；`node dist/cli.js task check` error 0 / warn 0

## 回滚

删除 `skill list` 命令注册与 `summary` 读取即可；已写入 state 的字段对旧版本无影响。
