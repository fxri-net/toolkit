# 为 README 能力矩阵补文案机检

> 计划位置：第 2 个（共 4 个）；前置：无；后继：无

## 背景

`README.md` 的能力矩阵是 2026-11-25 文案漂移点之一：6 个能力名与 CLI 页标题不一致，靠人工对齐后发现。矩阵一列对多页（docs 行指「文档站主题」「文档站校验」两页）、还含非页面能力（隐私脱敏、Node API），不能整体套用「文案 == H1」，但可对可唯一定位的行加机检。

## 实施方案

1. `scripts/check-consistency.mjs` 增能力矩阵校验：解析 `## ✨ 能力矩阵` 表；行首文案形如「显示名（标识）」且行内存在指向 `docs/cli/<标识>.md` 的链接时，文案须等于该页标题。
2. 其余行显式跳过并在注释写明判据：多页域（docs）、非页面能力（隐私脱敏、Node API）、无标识行、链接只指攻略锚点或非 CLI 页的行。
3. `src/__tests__/consistency-references.test.ts` 补假现场用例：能力名与 CLI 页 H1 一致时通过；不一致时报 error 并指出该行。

## 影响范围

- 触达：scripts/check-consistency.mjs、src/__tests__/consistency-references.test.ts
- 变更集：无（只改仓库自检与测试）

## 验证方式

1. `node scripts/check-consistency.mjs` 在真实仓库通过。
2. `pnpm exec vitest run src/__tests__/consistency-references.test.ts` 全绿。
3. 归档后 `pnpm verify`。
