## 背景

`engines.node` 声明 `>=18.17.0`，CI 只覆盖 18.17.0 与 20.x / 24。需在 18 及以上每个 Node 主版本上确认「已发布形态」的 CLI 可用：安装、加载交互组件、各域代表性命令、JSON 输出与退出码。上一轮同规格任务见 archive/202611/20261122.md「Node大版本矩阵测试」；本任务只测试与报告，不修复。

## 实施方案

1. 版本清单：18.17.0、18.20.8、19.9.0、20.20.2、21.7.3、22.23.5、23.11.1、24.22.3、25.9.0、26.13.1、27.0.0-alpha；以 fnm 实际可安装者为准，缺版本记 NOT RUN 并注明原因。
2. 每版流程：切换版本 → `pnpm install --frozen-lockfile` → `pnpm build` → `pnpm pack` → `npm i -g --prefix <临时前缀> ./fxri-toolkit-*.tgz` → 用临时前缀里的 `toolkit` 跑跨版本冒烟。
3. 跨版本冒烟集（沙箱内，不写真实 home）：`--version`、`--help`、`init`、`task list`、`task add --yes`、`skill status`、`skill install --dry-run --yes`、`rule compose --out`、`release status`、`docs nav check`、`scope status`、`usage record`、`status --format json` 信封解析、未知命令退出码、`--cwd` 生效。
4. 工具链补充：能跑测试套件的版本追加 `pnpm verify --tests-only`；Node 18 两版另跑 `scripts/smoke-node18.mjs --cli`。
5. 区分两类失败：产品运行失败（命令退出码或输出错误）与工具链不支持（Vite / Vitest 要求的 Node 下限更高，测试套件本身起不来）。
6. 重点回归：25 / 26 / 27 的 `localStorage` 冲突已修复，确认转 PASS；23 的软链用例预期仍有已知差异（EOL，产品命令不受影响）。
7. 中间脚本与 tgz、临时前缀均在仓库外临时目录，不进入仓库。
8. POSIX 分支：探测 WSL，可用则补跑关键命令，不可用记 NOT RUN。
