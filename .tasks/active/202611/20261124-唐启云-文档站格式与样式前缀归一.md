# 文档站格式与样式前缀归一

第 2 个（共 3 个）；前置：无；后继：无

## 背景

前端技能审计命中三处与项目既有约定不一致：

- **引号**（vue #1）：`.prettierrc` 为 `singleQuote: false`，但 `docs/.vitepress/config.mts` 全篇单引号（`from 'vitepress'`、`title: '方弦工具集'` 等）。
- **尾逗号**（vue #1）：`.prettierrc` 为 `trailingComma: "none"`，`docs/.vitepress/theme/components/diagrams/links.ts` 的 `PIPELINE_LAYERS`、`JOURNEY_LINKS`、`MODEL_LINKS` 三个数组末项带尾逗号。
- **前缀同源**（web #17）：项目设计令牌统一用 `--fx-`，本次新增的三个图示组件却用 `tk-` 类名前缀（`tk-map`、`tk-node`、`tk-card` 等），形成第三套前缀。

## 实施方案

1. `docs/.vitepress/config.mts`：单引号统一为双引号（import 与全部字符串字面量），不改任何配置值。
2. `docs/.vitepress/theme/components/diagrams/links.ts`：三个数组末项去尾逗号。
3. 三个图示组件（`ConceptMap.vue`、`TaskJourney.vue`、`ModelMap.vue`）：类名 `tk-*` → `fx-*`，模板与 `<style scoped>` 同步改，选择器与类名保持一一对应。
4. 不动 `docs/.vitepress/theme/index.ts` 与 `custom.css`（模板托管，逐字比对）。

## 影响范围

- 触达：`docs/.vitepress/config.mts`、`docs/.vitepress/theme/components/diagrams/links.ts`、三个图示组件。
- 只改书写形态与类名前缀，页面结构、文案、链接与视觉不变。
- 变更集：无（格式与内部类名，无对外行为变化）。
- 不做：不接入 prettier 全仓校验（会引发大面积重排，另议）；不批量重排存量 src 函数顺序。

## 验证方式

1. `docs:build` 后页面视觉与改前一致（三张图、节点跳转、亮暗主题抽查）。
2. 全仓 grep `tk-` 在三个组件内归零；`config.mts` 无双引号以外的引号。
3. `pnpm docs:build`、`pnpm verify` 通过。
4. 归档后 `pnpm verify`。
