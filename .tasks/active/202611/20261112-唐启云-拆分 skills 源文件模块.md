# 拆分 skills 源文件模块

> 计划位置：第 5 个（共 10 个）；前置：20261112-唐启云-拆分 conventions 等命令模块；后继：20261112-唐启云-拆分 skills 安装模块

## 背景

`src/skills/source.ts` 992 行，混装六类职责：包根解析与缓存、技能 frontmatter 读取、skills.json 清单解析、远程 Git 源与缓存、agent 目标目录解析、产物写入与薄壳模板。搜索结果与实际维护成本都集中在单文件定位上。

## 实施方案

1. 按职责拆为 `src/skills/source/` 下若干文件：
   - `root.ts`：`resolvePackageRoot`、`resetSkillsRootCache`、`setPackageRootForTest`、`skillsSourceDir`、`skillsPackageDir`、`packageVersion`、`pnpmStableEntry`、`skillsLinkDir`；
   - `frontmatter.ts`：`readSkillVersion` / `readSkillTier` / `readSkillRequires` / `readSkillPreviousNames` / `readSkillBodyVersion` / `readSkillDescription` / `readSkillName` 及其缩进读取实现；
   - `manifest.ts`：`SKILLS_MANIFEST_FILE`、`readManifest`、`packageSkill`、`listPackageSkills`、`assertSkillAliases`、`findSkillVersionMismatches`；
   - `remote.ts`：`RemoteSpec`、`parseRemoteSpec`、`resolveRemoteSource`、`refreshRemoteSource`、`git` 调用与缓存目录逻辑；
   - `targets.ts`：agent 表解析、`resolveSkillTargets`、`resolveTargetsByName`、`availableTargetNames`、`detectSkillScope`、`resolveProjectTargets`、`classifyTargetKind`、`targetId`、`skillTargetLabel`、`legacySkillDirLabel`；
   - `artifact.ts`：`classifyExisting`、`removeArtifact`、`copyArtifact`、`writeArtifact`、`buildSkillShell`、`readSkillShellVersion`、`currentSkillShellVersion`；
   - `paths.ts`：`pathKey`、`stripTailSep`、`pathPresent`、`isToolkitArtifactLink`、`isEmptyDir`、`sameDirContent`、`dirsEqual`、`realPath`、`isInside`、`toRepoRel`、`listDirEntries`。
2. `src/skills/source.ts` 保留为 barrel（`export * from "./source/xxx"`），或删除后由 `src/skills/index.ts` 直接导出新路径；无论哪种，`src/skills/index.ts` 对外导出名与签名必须保持不变。
3. 搬移中不得改动任何文件系统判定（软链识别、`realpath` 归一、大小写敏感与否）与错误文案。

## 影响范围

- 新增：`src/skills/source/` 下 7 个文件。
- 修改：`src/skills/index.ts`（导出路径）；删除或收缩 `src/skills/source.ts`。
- 文档影响：无（`docs/api.md` 只引用 `src/index.ts`，不引用本模块）。
- 变更集：patch 一条（优化：skills 源能力按职责拆分模块）。
- ⚠️ 与 `src/config.ts` 的 home 注入、`src/read-text.ts` 的 BOM 剥离调用关系保持不变，不得借机改写。
