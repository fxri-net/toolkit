# 技能分发页下沉收敛

> 计划位置：第 3 个（共 5 个）；前置：20261108-唐启云-问答页去冗余压缩；后继：20261108-唐启云-攻略任务规范节收敛

延续 命令参考页拆句（见 archive/202611/20261108.md）

## 背景

`docs/cli/skills.md` 现为 281 行 / 11,996 字符，`C-40` 上限 12,000 字符只剩 4 字符余量，行数也超出 250 行建议值 31 行。
该页把「目标选择」「作用域」的分发落点细节讲了两遍，而 `docs/config/skills.md` 的「分发目标与环境变量」节已承载同一事实。

## 实施方案

1. `docs/cli/skills.md` 保留 `## 目标选择` 与 `## 作用域` 两个标题（外部链接依赖这两个锚点），正文压成结论 + 指针：
   - 目标选择：三层顺序一句话（主目标 → 已安装 agent → `--dir` 兜底），候选目录清单与逐 agent 判定移走
   - 作用域：`--scope` 三值与缺省判定一句话，项目面真源 / 薄壳 / 归属账三行结论，其余细节移走
2. `docs/config/skills.md` 的「分发目标与环境变量」节接收移入内容：全局面三层目标、项目面候选目录表、`--dir` 与历史落点提示，按现有小节结构编排。
3. 链接检查：`docs/faq.md`、`docs/guide.md` 指向 `cli/skills#作用域` 的锚点保持不变；不新增页面、不改侧边栏。
4. 目标：行数 ≤250、字符 ≤11,500（留 ≥500 余量）；两页均保持可读性 0 超标。

## 影响范围

- 文档触达：docs/cli/skills.md、docs/config/skills.md
- 锚点：`## 目标选择`、`## 作用域` 两个标题保留，锚点不失效
- 不新增页面、不改 `docs/.vitepress/config.mts`：仅在既有两页之间搬内容
- 不建变更集：`docs/` 不随包分发

## 验证方式

1. `docs/cli/skills.md` 行数 ≤250、字符 ≤11,500；`docs/config/skills.md` 行数与字符记录变化
2. `node scripts/check-docs-readability.mjs` 全仓 0 处超标
3. `pnpm docs:build` 通过（跨页链接与锚点）
4. `pnpm verify` 全绿
