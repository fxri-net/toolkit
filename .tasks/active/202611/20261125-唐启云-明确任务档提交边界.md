# 明确任务档提交边界

> 计划位置：第 4 个（共 4 个）；前置：无；后继：无

## 背景

2026-11-25 首个任务的交付提交连带入库了另外两个尚未开工的任务档，与「规划期修订不进提交」有偏差。现有技能只写「规划期修订不进提交」，未写明交付提交与其他未开工任务档的边界，靠口头约定容易复发。

## 实施方案

1. `skills/fxri-plan-task/SKILL.md` 的收尾边界补一句：交付提交只带本任务归档产物与代码改动；其他未开工任务档另起提交，不随本任务混批。
2. 技能版本 1.13.3 → 1.13.4，frontmatter `metadata.version` 与正文首部两处同步；`skills/README.md` 与 `docs/guide.md` 的技能表版本同步。
3. 新建 patch 变更集，条目为 `- 修改：明确任务档提交边界，未开工任务档不随交付任务混批`。

## 影响范围

- 文档触达：skills/fxri-plan-task/SKILL.md、skills/README.md、docs/guide.md
- 变更集：patch（技能正文变更，随包分发）

## 验证方式

1. `pnpm exec vitest run src/__tests__/consistency-references.test.ts` 通过（技能版本四点一致由 `check-consistency` 校验）。
2. 归档后 `pnpm verify`。

## 回滚

单提交回退技能正文、版本号与变更集。
