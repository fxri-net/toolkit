# 攻略任务规范节收敛

> 计划位置：第 4 个（共 5 个）；前置：20261108-唐启云-技能分发页下沉收敛；后继：20261108-唐启云-规范载体分册拆分

延续 指南问答页拆句（见 archive/202611/20261108.md）

## 背景

`docs/guide.md` 现为 295 行 / 11,781 字符，行数超出 `C-40` 的 250 行建议值 45 行，字符也只剩 219 余量。
其中「任务文件规范」整节（目录树、frontmatter 字段表、归档规则要点）与根 `SPEC.md`、`docs/cli/tasks.md` 三处重复承载同一事实。

## 实施方案

1. 「任务文件规范」节保留标题与首段定位，把三块重复内容收敛：
   - 目录树：删掉逐行注释版，改为一句「目录骨架见 SPEC」，保留 `active/archive/conventions` 三行极简示意
   - frontmatter 字段表：整表删除，指向 `SPEC.md` 与 `docs/cli/tasks.md` 的字段说明
   - 归档规则要点：保留四条结论各一句，删去与 `docs/cli/tasks.md#normalize` 重复的参数细节
2. 同步核对指向 `guide#任务文件规范` 的链接（`docs/api.md`、`docs/cli/tasks.md`、`docs/handbook.md`）：标题保留即锚点不失效，无需改链接。
3. 「AI 技能包 skills」节重复的安装参数收敛为一句 + 指向 `docs/cli/skills.md`，避免与第 3 个任务的收敛结果互相矛盾。
4. 目标：行数 ≤250、字符 ≤11,500；语义不丢事实，细节全部有真源可去。

## 影响范围

- 文档触达：docs/guide.md
- 锚点：`## 任务文件规范` 标题保留；`#frontmatter-字段` 等子锚点若被删除，须先 grep 全仓引用并改指
- 不新增页面、不改侧边栏
- 不建变更集：`docs/` 不随包分发

## 验证方式

1. `docs/guide.md` 行数 ≤250、字符 ≤11,500
2. `node scripts/check-docs-readability.mjs` 全仓 0 处超标
3. `pnpm docs:build` 通过；链接与锚点测试通过
4. `pnpm verify` 全绿
