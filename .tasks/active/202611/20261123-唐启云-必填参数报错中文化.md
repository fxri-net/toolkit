# 必填参数报错中文化

> 计划位置：第 2 个（共 2 个）；前置：20261123-唐启云-三方一致措辞修订；后继：无

## 背景

`docs/cli/exit-codes.md` 承诺「未知命令、未知选项、参数个数不符等解析错误统一输出中文提示，不再混出 commander 英文原文」；
但 `formatCommanderError` 只覆盖未知命令 / 未知选项 / 参数过多，缺 `commander.missingArgument` 与
`commander.missingMandatoryOptionValue`，实测 `toolkit usage log --skill x` 缺 `--session` 时输出英文
`error: required option '--session <id>' not specified`。

## 实施方案

1. `src/errors.ts`：补两个分支——缺位置参数输出「缺少必填参数「x」」；缺必填选项输出「缺少必填选项「--flag」」，
   均附统一帮助指引。
2. `src/__tests__/errors.test.ts`：把 `missingArgument` 的 null 期望改为中文；补 `missingMandatoryOptionValue` 用例。
3. 新增 patch 变更集。

## 影响范围

- 端：toolkit（本仓库单端）。
- 文件：`src/errors.ts`、`src/__tests__/errors.test.ts`、`.changeset/required-option-chinese.md`（新增）。
- 文档说明：`docs/cli/exit-codes.md` 的承诺本已存在，本次为行为向其收敛；README、docs 其余页与 skills 无触达。
- conventions：无对应条目，语义不变。
- 规则层更新锚点：未变更规则层，不抬锚点。
- 变更集：`.changeset/required-option-chinese.md`（patch）。

## 验证方式

- `errors.test.ts` 正反用例通过。
- 实测 `toolkit usage log --skill x` 输出中文「缺少必填选项「--session <id>」」并以 1 退出。
- `pnpm verify` 全绿。
- 回滚：单提交回退 `errors.ts` 与测试。
