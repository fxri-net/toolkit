# 拆分 skills 安装模块

> 计划位置：第 6 个（共 10 个）；前置：20261112-唐启云-拆分 skills 源文件模块；后继：20261112-唐启云-拆分 usage 命令模块

## 背景

`src/skills/install.ts` 1202 行，同时承载全局安装（`installSkills`）、项目面安装（`installProjectSkills`）、全局卸载（`removeSkills`）、项目面卸载（`removeProjectSkills`）、链接自愈（`autoLinkSkills`）与选择集/目标持久化六段流程，且全局面与项目面各有一套近似但不同的保存与清理逻辑。

## 实施方案

1. 拆为 `src/skills/install/`：
   - `common.ts`：`collectSources`、`collectSkillItems`、`filterSkillItems`、`skillTargetsBySource`、`sourceSkillMap`、`recordAction`、`applySourceCopy`、`applyShell`、`orphanArtifactRemovable`、`consistentSourceCopy`、`consistentShell`；
   - `global.ts`：`installSkills`、`saveGlobalSelection`、`saveGlobalTargets`、`writeGlobalSources`、`clearGlobalSelection`、`removeSourceConfig`、`pruneEntries`；
   - `project.ts`：`installProjectSkills`、`saveProjectSelection`、`saveProjectTargets`、`writeProjectSources`、`clearProjectSelection`；
   - `remove.ts`：`removeSkills`、`removeProjectSkills`；
   - `autolink.ts`：`autoLinkSkills`。
2. `src/skills/index.ts` 的导出名与签名保持不变；`src/skills/install.ts` 可保留为 barrel 或删除。
3. **禁止合并全局面与项目面流程**：两者在路径、状态文件、忽略目录告警、清理口径上存在实质差异，任何「抽公共流程」都属行为变更。
4. 搬移中不得改动锁的获取顺序（`acquireSkillsLock` 包裹范围）与 dry-run 语义。

## 影响范围

- 新增：`src/skills/install/` 下 5 个文件。
- 修改：`src/skills/index.ts`；删除或收缩 `src/skills/install.ts`。
- 文档影响：无（`docs/cli/skills.md` 描述的是行为，本次不变）。
- 变更集：patch 一条（优化：skills 安装与卸载流程按面拆分模块）。
- ⚠️ `src/cli.ts` 中对这些函数的调用只改 import 路径，不改参数与顺序。

- `pnpm vitest run src/__tests__/cli-golden.test.ts`：快照 0 diff。
- `pnpm verify` 全量通过。
