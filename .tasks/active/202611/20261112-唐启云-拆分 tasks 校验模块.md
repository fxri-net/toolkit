# 拆分 tasks 校验模块

> 计划位置：第 8 个（共 10 个）；前置：20261112-唐启云-拆分 usage 命令模块；后继：20261112-唐启云-收敛同语义基础设施

## 背景

`src/tasks/validate.ts` 613 行，把三类互不相干的校验混在一起：单任务文件校验（frontmatter 字段、范围端点、日期真实性、游离待办）、规范载体校验（conventions 索引表形态与历史列）、归档依赖校验（跨任务 depends_on 成环）。`src/index.ts` 从该文件公开导出 `validateTaskFile`、`validateTasks` 与相关类型。

## 实施方案

1. 拆为：
   - `src/tasks/validate.ts`：保留为公开出口，导出 `validateTaskFile`、`validateTasks`，内部编排三类校验；
   - `src/tasks/validate-file.ts`：`findPendingHit`、`isRealDate`、`fmKeyLine`、`bodyLine`、`hygieneIssues`、`readDeclaredEndpoints` 与单文件校验主体；
   - `src/tasks/validate-conventions.ts`：`validateConventions`、`validateTableShape`、`validateTableForm`、`validateHistoryIdColumn`；
   - `src/tasks/validate-deps.ts`：`validateDependencies`、`archivedTitles`、`strayTaskFiles`、`localConfigIssues`。
2. `src/index.ts` 的导出路径与签名不变；`CheckIssue` / `CheckResult` / `IssueLevel` 类型定义位置不变。
3. 校验条目顺序与消息文本必须逐字保持——`tasks check` 与 `cli-golden` 快照都依赖顺序稳定。

## 影响范围

- 新增：`src/tasks/validate-file.ts`、`src/tasks/validate-conventions.ts`、`src/tasks/validate-deps.ts`。
- 修改：`src/tasks/validate.ts`（收缩为出口 + 编排）。
- 文档影响：无（`tasks check` 输出不变）。
- 变更集：patch 一条（优化：任务校验按校验类别拆分模块）。
- ⚠️ `src/tasks/normalize.ts` 与 `conventions/status.ts` 对校验结果的消费方式不变，不得同步改动其判定。
