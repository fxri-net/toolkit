# 规范载体分册拆分

> 计划位置：第 5 个（共 5 个）；前置：20261108-唐启云-攻略任务规范节收敛；后继：无

延续 技能文档拆句与门禁收紧（见 archive/202611/20261108.md）

## 背景

`skills/fxri-plan-to-task/references/conventions-spec.md` 已达 322 行 / 13,830 字符，是技能包里最重的常读文件：
前 3 节讲载体结构（目录、index 结构、分册与留痕文件），后 11 节讲读写判定与维护动作（端名、读取 / 写入判定、形态、修订、
表格、迁移、兼容读、自查、文风、检测入口）。技能被触发时按「读取地图」整篇加载，后段维护细则多数场景用不上。

## 实施方案

1. 拆为两份 references：
   - `conventions-spec.md` 保留 §1–§3（载体结构、index.md 结构、分册与留痕文件），约 198 行
   - 新增 `conventions-maintenance.md` 承载 §4–§14（端名规则、读写判定、两种形态、内容修订、表格形态、存量迁移、兼容读、自查清单、文风、检测入口），约 124 行
2. `skills/fxri-plan-to-task/SKILL.md` 的「读取地图」与正文引用改为「结构读 spec、维护读 maintenance」，两处都点名；
   核对 `fxri-session-recap/SKILL.md` 等引用 `conventions-spec.md` 的位置，按其语境决定是否改指新文件。
3. `fxri-plan-to-task` 版本递增 patch（1.10.4 → 1.10.5），四处写位同步：`SKILL.md` frontmatter `metadata.version`、
   正文首行「本技能版本」、`skills/README.md` 技能表版本列、`docs/guide.md` 技能表版本列。
4. 建变更集 `.changeset/skills-conventions-split.md`（patch，`- 文档：…` 条目）。
5. 拆分后两份文件均保持可读性 0 超标；不新增或删除任何规则条文。

## 影响范围

- 文档触达：skills/fxri-plan-to-task/references/conventions-spec.md、skills/fxri-plan-to-task/SKILL.md、skills/fxri-session-recap/SKILL.md、skills/README.md、docs/guide.md
- 新增文件：`skills/fxri-plan-to-task/references/conventions-maintenance.md`（执行时创建，不在触达登记内，因校验要求路径先存在）
- 变更集：`.changeset/skills-conventions-split.md`（patch）
- 语义零变化：条文只搬家不改写，版本递增只因内容重排
- `check-consistency.mjs` 三项校验须仍通过（版本四点一致、用途列、触达路径存在）

1. 两份 references 行数分别 ≤200 与 ≤150，`node scripts/check-docs-readability.mjs` 全仓 0 处超标
2. `node scripts/check-consistency.mjs` 无 error / warn
3. `grep -rn "conventions-spec.md" skills/` 的引用均指向存在文件且语义正确
4. `pnpm verify` 全绿
