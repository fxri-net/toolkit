# 补文档非交互与裸文档站口径

> 计划位置：第 2 个（共 5 个）；前置：20261123-唐启云-修复归档时间单数字分钟归一；后继：20261123-唐启云-隔离状态单测弃用缓存

## 背景

功能全量测试发现两处文档口径不完整：

1. `release changeset add` 是 changesets 的交互式命令；非 TTY 下会打印交互界面并以 0 结束，但不会创建变更集。现有文档只写「原样透传、退出码原样返回」，未提示这一结果。
2. 裸 `toolkit docs` 在完全没有 `docs/` 目录时输出「未检测到文档站，跳过」并退出 0；现有文档只写「默认全量校验」，未区分「无目录跳过」与「目录存在但不完整退 1」。

## 实施方案

1. `docs/cli/release.md`：在透传子命令条目处补一句——`changeset add` 为交互式命令，非 TTY 下不会创建变更集，请在真实终端运行。
2. `docs/cli/docs-check.md`：「退出码与输出」节补一条——未检测到 `docs/` 目录时裸 `docs` 跳过并退出 0；`docs/` 存在但缺主题 / 导航文件时按校验结论退出 1。
3. `docs/cli.md`：裸命令规则处补同一 docs 例外口径，与 docs-check 页一致。
4. 新增 patch 变更集，条目以 `- 文档：` 前缀书写。

## 影响范围

- 端：toolkit（本仓库单端）。
- 文件：`docs/cli/release.md`、`docs/cli/docs-check.md`、`docs/cli.md`、`.changeset/docs-cli-noninteractive-notes.md`（新增）。
- 文档触达：
  - `docs/cli/release.md`、`docs/cli/docs-check.md`、`docs/cli.md`：已同步。
  - `README.md`、`docs/changelog.md`（生成物）与其余 `docs/**/*.md`：无触达。
- skills：无触达。
- conventions：无对应条目，语义不变。
- 规则层更新锚点：未变更规则层，不抬锚点。
- 变更集：`.changeset/docs-cli-noninteractive-notes.md`（patch）。

## 验证方式

- `pnpm verify` 全绿（含文档类型检查、文档可读性与站内链接锚点）。
- 逐句核对新增措辞与实际行为：非 TTY `changeset add` 退 0 不落盘；无 `docs/` 目录裸 `docs` 退 0，空 `docs/` 目录退 1。
- 回滚：单提交回退三处文档与变更集。
