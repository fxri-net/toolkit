# 覆盖率纳入与命令注册收口

> 计划位置：第 10 个（共 10 个）；前置：20261112-唐启云-收敛同语义基础设施；后继：无

## 背景

拆分完成后，`src/commands/**` 承载全部用户可见行为，但 `vitest.config.ts` 仍沿用「排除 `src/cli.ts`」的旧口径。若不调整，最大的行为面长期处于覆盖率盲区；同时各域注册函数形态已基本统一，可做一次一致性收口。

## 实施方案

1. 调整 `vitest.config.ts` 的 `coverage.exclude`：移除 `src/cli.ts`，改为由 `src/commands/**` 与 `src/cli.ts` 共同计入统计；先实测一次基线数值，再决定是否保持现有阈值（statements 80 / branches 65 / functions 80 / lines 82），**阈值只允许不下调**。
2. 命令注册模式统一：确认 `init / skills / tasks / changelog / conventions / config / rules / docs-theme / usage` 九个域全部以 `registerXxxCommands(program)` 形式暴露，且 `src/cli.ts` 只按序调用。
3. 若实测覆盖率低于阈值：优先补测 `src/commands/**` 的真实分支（help 树、错误路径），不以降低阈值或加 exclude 的方式过关。
4. 不加新依赖、不换测试框架、不改构建目标。

## 影响范围

- 修改：`vitest.config.ts`；可能新增 `src/__tests__/` 下的命令层用例。
- 文档影响：无。
- 变更集：patch 一条（优化：命令层纳入覆盖率统计）。
- ⚠️ 覆盖率口径变更属 CI 门禁变更，须与 `scripts/verify.mjs` 的调用方式保持一致（该脚本以 `--coverage` 调 vitest，不改其步骤清单）。

## 验证方式

- `pnpm test:coverage` 通过且各项不低于阈值。
- `pnpm vitest run src/__tests__/cli-golden.test.ts`：快照 0 diff。
- `pnpm verify` 全量通过。
