# 技能矩阵向导

> 计划位置：第 4 个（共 5 个）；前置：20261121-唐启云-作用域策略配置加载、20261121-唐启云-作用域策略命令面；后继：20261121-唐启云-技能矩阵联动与文档

## 背景

命令面能精确落规则，但日常配置仍希望像 scope 其它页面一样逐步选择。本任务在现有 `scope wizard` 增加「技能矩阵」页，
复用交互基座与命令面的计划层，不另写一套写盘逻辑。

## 实施方案

1. 主菜单新增「技能矩阵…」入口，仅在已选配置层内工作，页头回显当前层与已有规则数。
2. 子页流程：选择作用范围（当前项目 / 手动输入项目与子路径 / 扫描选择）→ 选模式（只允许列出的技能 / 全部允许但排除）→
   勾选技能或档案（空格切换、回车确认）→ 可选高级条件（markers / gitRemotes，留空跳过）→ 预览 → 确认写入。
3. 只允许模式下支持勾选档案并追加单个技能；全部允许模式只收集排除项。
4. ESC 逐级返回：预览 → 技能选择 → 范围 / 模式 → 主菜单；Ctrl+C 退出码 130，取消文案与其它页统一。
5. 空现场给出可执行提示（先选技能或先建档案），不写空规则；补向导单测覆盖前进、回退与取消。

## 影响范围

- 代码：`src/scope/wizard.ts`、`src/scope/edit-policy.ts`（复用）
- 测试：`src/__tests__/scope-wizard.test.ts` 与新增矩阵页用例
- 文档触达说明：本任务无触达，策略文档统一在任务 5 落地
- 变更集：patch（按设计缺陷补全口径，向导新增技能矩阵页，独立记录）

## 验证方式

- 向导逐级前进、ESC 返回、取消不写盘
- 写入结果与 `scope skills list` 一致
- `pnpm verify` 全量通过
