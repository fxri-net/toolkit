# 存量命名统一与封装收敛

> 计划位置：第 4 个（共 4 个）；前置：20261121-唐启云-环境变量前缀收编FX；后继：无

## 背景

命名规范（`C-45`）落地后，存量仍有三类不一致，需按规则收敛：

- 谓词不标准（8 处）：
  - `src/conventions/cells.ts` L55 `lacksRoutingColon`（负向命名）
  - `src/conventions/format.ts` L241 `outsideFenceMask`（名字像谓词、实际返回掩码）
  - `src/tasks/name.ts` L34 `briefMatchesTitle`（`matches` 属允许形态，列为核对项）
  - `src/skills/install/common.ts` L163 `orphanArtifactRemovable`、L221 `consistentSourceCopy`、L226 `consistentShell`
  - `src/skills/source/paths.ts` L21 `pathPresent`、L62 `sameDirContent`、L67 `dirsEqual`
- 参数简写：`cfg` 出现在 `src/docs/nav.ts`、`src/docs/dist.ts`、`src/privacy/redact.ts`；`opts` 出现在 `src/tasks/import.ts`
- 绕过封装：`src/changelog/format.ts`、`src/changelog/audit.ts`、`src/init.ts`、`src/skills/bump.ts` 等仍直接调用 `readFileSync` / `writeFileSync`，与 `readTextFile` / `writeFileAtomic` 并存

## 实施方案

1. 谓词改名（逐处同步调用点）：
   - `lacksRoutingColon` → `hasRoutingColon`，调用处取反
   - `outsideFenceMask` → `buildOutsideFenceMask`
   - `pathPresent` → `isPathPresent`
   - `sameDirContent` → `isSameDirContent`
   - `dirsEqual` → `isSameDir`
   - `orphanArtifactRemovable` → `canRemoveOrphanArtifact`
   - `consistentSourceCopy` → `isConsistentSourceCopy`
   - `consistentShell` → `isConsistentShell`
   - `briefMatchesTitle` 保持（`matches*` 属规范允许的匹配类谓词），仅核对
2. 参数改名：`cfg` → `config`（3 个文件）、`opts` → `options`（`src/tasks/import.ts`），同步局部变量与类型引用
3. 封装收敛：非二进制读取统一 `readTextFile`，非临时写入统一 `writeFileAtomic`，主目录解析统一 `getHomeDir`；逐文件核对例外（如 `write-atomic.ts` 自身的底层写入、`config.ts` 内 `getHomeDir` 的实现体）并在代码注释说明原因
4. 公共导出：被改名符号均不在 `src/index.ts` 的导出清单内（`docs/api.md` 与 `src/index.ts` 同源），无需保留别名；执行时以 `grep` 复核，若实际存在公共导出则补弃用别名
5. 文档：`docs/api.md` 无触达（不列出上述内部符号），执行时 grep 复核

## 影响范围

- 代码：`src/conventions/cells.ts`、`src/conventions/format.ts`、`src/tasks/name.ts`、`src/skills/install/common.ts`、`src/skills/source/paths.ts`、`src/docs/nav.ts`、`src/docs/dist.ts`、`src/privacy/redact.ts`、`src/tasks/import.ts`、`src/changelog/format.ts`、`src/changelog/audit.ts`、`src/init.ts`、`src/skills/bump.ts`
- 文档：无触达（`docs/api.md` 与 `src/index.ts` 同源，被改名符号不在导出清单；执行时 grep 复核）
- 规范载体：无（规则本体由任务 1 落条）
- 无触达：`docs/cli/*`、`docs/config/*`、`docs/usage/*`（不描述内部函数名）；`README.md`
- skills：无触达
