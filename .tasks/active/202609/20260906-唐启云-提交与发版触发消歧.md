# 提交与发版触发消歧

## 背景

用户说「先提交个版本 / 提交一下 / commit 这版」等口语时，语义大概率是 **git 提交当前改动**（走任务收尾后提交），但「出个版本」是 fxri-release-changelog 的显式触发词——AI 易把「提交个版本」误判为发版意图，误触发发版链路（消费变更集、改 CHANGELOG），风险等级高于漏触发。

## 实施步骤

1. fxri-release-changelog SKILL.md（1.0.5 → 1.0.6）：description + 「何时使用」补反例排除：
   - 「提交个版本 / 先提交一版 / commit」通常指 git 提交当前改动（走任务收尾后提交），**不是发版**
   - 仅在用户明确表达发布/生成 CHANGELOG 时才进入本技能
2. 文档触达核对（变更方案确认时走查，结论列入影响范围）：见下表
3. 变更集：patch（release-changelog 1.0.6）
4. 门禁：tasks check 0/0、grep 措辞落地
5. 收尾：归档 → conventions 沉淀 → 提交（先给用户确认）
