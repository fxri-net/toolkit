# AGENTS 发版链路补推送步骤

## 背景

「推送」无流程归属：release-changelog 到 publish 为止，AGENTS.md 发版链路也不含 git 推送，用户说「推送」时靠 AI 临场处理。需在 AGENTS.md 发版链路补一步推送，语义为**动态遍历全部已配置 remote**（配几个推几个，不硬编码端名），推送前经用户确认；用户显式指定单端时按其字面只推该端。

## 实施步骤

1. AGENTS.md 发版链路第 5 步 publish 后新增第 6 步：
   - 推送：`git remote` 遍历当前全部已配置远端（配几个推几个，数量不固定），推送前向用户列出将推送的远端清单经确认后执行；用户显式指定单端（如「先推 github」）时只推该端，不套用全量
2. 文档触达核对（方案确认时走查）：发版链路描述仅存在于 AGENTS.md（仓库治理层），docs 各篇不描述本仓库推送流程——见影响范围表
3. 门禁：tasks check 0/0、grep 措辞落地
4. 收尾：归档 → conventions 沉淀（如适用）→ 自动提交
