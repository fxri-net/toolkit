# 文档站首页改版为home布局

## 背景

docs/index.md 为普通文档页（一级标题+表格），作为 VitePress 站点门面观感弱。美化评估结论：仅做首页 home layout 一项，正文排版与自定义主题/logo 不做。docs 不随 npm 包发布，仅影响 GitHub Pages 站点。

## 实施项

- [ ] A. index.md 改 frontmatter layout: home，配 hero（标语+行动按钮）与 features 能力卡片
- [ ] B. 正文精简：能力矩阵表由 features 卡片取代，保留痛点表、30 秒上手、文档索引等关键节
- [ ] C. pnpm docs:build 本地验证 + 补 patch 变更集（文档类变更）
- [ ] D. tasks check error/warn 双清零，取真实时间归档，归档文件与代码变更同批提交

## 验收标准

- docs:build 通过，首页呈现 hero 与 features 卡片
- features 文案与实际能力一致（能力三方真实一致门）
- patch 变更集就绪；check 双清零；归档并同批提交
