# 修正历史归档任务时间

## 背景

早期归档（20260903 / 20260905 等）按旧规则沉淀，部分块的 completed 可能是收尾时刻而非任务真实发生时刻。本次按 fxri-session-recap 模式三批量修正：先侦查判定系统性/零星偏差，取证后交用户逐条确认，再改值 + `normalize --fix` 迁移核验。

## 实施步骤

1. 侦查：抽样本对照 git log（`git log --format="%h %ci"`）与归档块 completed，判断偏差形态（系统性后移 / 零星不准 / 基本准确）
2. 取证：列出疑似错时任务清单，每条附证据（git 提交时间 / 聊天记录时间戳，标注四级时间源级别）
3. 确认：清单交用户逐条确认正确时间
4. 修正：active 改文件 completed；归档块改元数据行完成时间
5. 迁移核验：`toolkit tasks normalize --fix` 自动迁移漂移块 → `normalize` 只读核验 0 漂移
6. 收尾：归档 → conventions 沉淀（如发现新规范）→ 提交

## 影响范围

- .tasks/archive 归档块时间与位置（数据修正，无能力代码变更）
- 不新增变更集（无对外行为变更）

## 验证与回滚

- normalize 0 漂移；git 可追溯每次改动；回滚 git revert
