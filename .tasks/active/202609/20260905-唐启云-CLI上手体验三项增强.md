# CLI 上手体验三项增强

## 实施方案

1. **help footer 文档链接**：program.addHelpText('after', ...) 输出新手指南/完整攻略/站点链接（GitHub 站点地址）
2. **toolkit init**：新增顶层命令（与 tasks/changelog 平级）
   - 生成 .tasks/ 骨架（active/{YYYYMM}/、archive/）
   - 生成 .gitignore 片段（.archive.lock，已存在则跳过不重复写）
   - 完成后输出新手指南与完整攻略链接
3. **升级检查提示**：CLI 命令执行末尾异步查 npm registry latest 版本
   - 落后时输出一行升级提示（含升级命令与「升级后开新会话」⚠️ 提示）
   - 24h 缓存（tmp 目录）、超时/离线/内网静默失败、默认可关

## 影响范围

- src/cli.ts（新增 init 命令、addHelpText、升级检查模块 src/update-check.ts）
- 新增单测覆盖 init 骨架生成、缓存窗口、静默失败
- CLI 描述文案与 docs/cli.md 同步

## 验证方式

- 全量门禁 + CLI 冒烟：init 在空目录生成骨架、重复执行幂等、help footer 链接正确
- 升级检查：断网静默、mock 落后版本输出提示
