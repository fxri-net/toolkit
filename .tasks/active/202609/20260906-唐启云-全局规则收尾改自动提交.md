# 全局规则收尾改自动提交

## 背景

用户个人工作流希望任务收尾的 git 提交自动执行（不再每次展示清单请确认），推送与发版仍保留确认。该偏好属于用户规则层的个性化收紧——skill 收尾边界已留出口（「提交取决于用户规则」），因此只改 docs/ai-rules.md 的个人模板，不改 skill。

## 实施步骤

1. docs/ai-rules.md 规则全文：稳定纪律第 5 条「归档 + 规范沉淀即流程终点；提交、发版、推送不是必经步骤，需用户明确」改为「归档 + 规范沉淀即任务流程终点；**任务收尾的 git 提交自动执行**（作者个人收紧：先归档与沉淀、后提交，归档文件与 conventions.md、代码变更同一 git 提交）；推送与发版仍需用户明确」，并标注「作者个人收紧，可参考可裁剪」
2. docs/ai-rules.md 逐段说明：同步收尾语义说明一行
3. 变更集：patch（docs 模板调整）
4. 门禁：tasks check 0/0、grep 措辞落地、docs:build 通过
5. 收尾：归档 → conventions 沉淀（如适用）→ 自动提交
