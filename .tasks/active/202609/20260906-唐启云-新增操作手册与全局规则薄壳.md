# 新增操作手册并收敛全局规则薄壳

## 背景

1. 操作指引分散在各 docs，缺一份用户可直接照着做的「完整操作说明」——从开发规范与规则提炼，覆盖全部能力闭环，服务零基础用户 / 只用 AI 用户 / 手操 CLI 用户三类人
2. 全局规则（docs/ai-rules.md 规则全文）复述了 skill 可变细节，导致能力升级后全局规则副本需手动同步，麻烦且易漏——需收敛为薄壳 + 引用 skills，并把「全局规则跟随能力」固化为项目规范

## 目标

1. 新增独立操作手册页（docs/handbook.md），按「用户场景 → 该说什么 → 会发生什么」组织
2. ai-rules.md「规则全文」瘦身为薄壳：只承载稳定纪律 + 对 fxri-* skill 的引用，不复述可变细节
3. AGENTS.md 质量门新增「全局规则薄引用」规则
4. 文档触达面全量同步 + 变更集 + 收尾沉淀

## 实施步骤

1. 新增 docs/handbook.md 操作手册：首次使用（安装/init/skills/全局规则模板）、日常开发 AI 模式、日常手操 CLI、会话边界（收尾/恢复）、数据进出（导入导出）、发版、升级（CLI + skills + 全局规则三步）、历史修正——每场景给「用户该说什么 → 会发生什么」
2. docs/ai-rules.md 瘦身：
   - 「方案落盘」「会话记忆」两段的可变细节改为引用已加载的最新 fxri-* skill，本规则只保留稳定纪律（方案先行确认、check 质量门、先归档沉淀后提交、AI 不自行全局安装）
   - 「配套安装」补升级同步说明：装 skills 后升级只跑 `pnpm dlx skills update --global`，无需再手动同步规则全文
3. AGENTS.md「能力变更三方真实一致」质量门追加第 5 条「全局规则薄引用」
4. 文档触达：docs/index.md 文档索引加操作手册；getting-started/faq 指向 handbook
5. 变更集：patch（docs 级，无能力行为变更）
6. 收尾：本任务归档 → conventions 沉淀 → 提交（先给用户确认）

## 影响范围

- docs/handbook.md 新增、docs/index.md / getting-started.md / faq.md 触达、ai-rules.md 瘦身、AGENTS.md 质量门扩展
- skills 不动（可变细节已在 skills 内，本次只删 ai-rules 中的复述）
