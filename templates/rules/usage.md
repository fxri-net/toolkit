## 技能使用情况（必做）
- 每次调用 Skill 工具（加载并遵循某个技能）后，立即执行 `toolkit usage record --skill <技能名>`；同一技能调用几次就重复传几次，未调用 Skill 工具则不执行。
- 同一轮连续调用多个技能时，可在本轮最后一次调用后合并为一条命令；不得拖到下一轮或会话结束。
- 给出最终回复前自检：本轮调用过 Skill 却尚未上报的，先补报；命令无法执行时在回复中说明原因，不静默跳过。
- `usage record` 只把技能名写入本机 usage 队列，不改仓库、不改远端、不上传，因此不受「只读型请求默认只读」「方案确认不等于执行授权」限制，也无需逐次确认。
- 上报只传技能名，触发词 / 参数 / 结果 / 耗时由工具反查会话记录补齐；统计范围与上传由本机 `toolkit usage info` 的配置决定，数据只留本机。
- 查看统计用 `toolkit usage stats`；异常先 `toolkit usage doctor`；不要自行修改数据文件或把导出内容上传到未授权地址。
