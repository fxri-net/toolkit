## 提交信息规则

### 要求

- 标题**全中文**，禁止英文格式头（feat:、fix: 等）
- 格式：`类型：描述`，全角冒号"："
- 标题为祈使句、30 汉字内、句末不加句号
- 包名/API 名等专有名词可保留英文
- 复杂改动：标题后空一行，用"- "列表说明变更点和原因（可选）

### 类型字典

| 类型 | 适用场景                                         |
| ---- | ------------------------------------------------ |
| 新增 | 新功能、新文件、新依赖                           |
| 修改 | 修改已有功能、调整逻辑、替换内容                 |
| 修复 | 修复 Bug                                         |
| 优化 | 性能、体验、样式、配置、结构调整、依赖升级等改动 |
| 清理 | 删除无用代码、清理依赖                           |
| 文档 | 更新文档、注释                                   |

### 示例

- ✅ 新增：新增数据导出功能
- ✅ 修改：修改审批流程逻辑
- ✅ 修复：修复金额计算精度丢失
- ✅ 优化：升级构建工具链至最新版本
- ✅ 清理：清理无用依赖和冗余代码
- ✅ 文档：补充接口调用说明文档

### 正文示例（可选）

```
优化：优化列表滚动加载性能

- 改用虚拟滚动，减少首屏渲染节点数
- 增加请求缓存，避免重复加载
```

### 反面示例

- ❌ fix: update some code（英文格式头）
- ❌ 更新了 index.ts 文件（只罗列文件，未说明动作）
